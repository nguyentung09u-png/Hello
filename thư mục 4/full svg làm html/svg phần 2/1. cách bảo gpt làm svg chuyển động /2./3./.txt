1. nhúng svg vào html để không lag

Để đạt được hiệu ứng mượt mà như vậy, hệ thống kết hợp 3 tầng kỹ thuật cốt lõi dưới đây, bao gồm tổng quan cách làm và mã nguồn minh họa tổng hợp.
I. Tổng quan cách thực hiện
 * Đồ họa SVG vector độc lập:
   * Dùng thẻ <svg> và các lệnh hình học (<path>, <circle>) để vẽ nhân vật.
   * Chia nhỏ nhân vật thành các nhóm thành phần riêng biệt (thân, đuôi, vây, tia nước) nằm trong các thẻ nhóm <g>.
 * Khớp xương chuyển động bằng CSS Keyframes:
   * Sử dụng thuộc tính transform-origin để định vị chính xác tâm xoay của từng bộ phận (ví dụ: gốc đuôi, gốc vây).
   * Dùng @keyframes để tạo các chu kỳ lặp lại (vẫy đuôi, quạt vây, nhấp nhô) với tốc độ khác nhau.
 * Điều hướng tự động bằng JavaScript (60fps trên GPU):
   * Dùng vòng lặp requestAnimationFrame kết hợp toán học vector (gia tốc, vận tốc) để tạo đường bơi tự nhiên.
   * Dùng translate3d và thuộc tính will-change: transform để trình duyệt đẩy tác vụ xử lý đồ họa sang card màn hình (GPU), giúp khung hình luôn ổn định.
II. Code chung chung (Tích hợp tất cả trong 1 file HTML)
Đoạn code dưới đây tích hợp đầy đủ SVG, CSS Keyframes và JavaScript điều khiển chuyển động:
<!DOCTYPE html>
<html lang="vi">
<head>
  <meta charset="UTF-8">
  <title>Mô phỏng SVG Chuyển động Mượt mà</title>
  <style>
    body {
      background: #07070C;
      margin: 0;
      height: 100vh;
      overflow: hidden;
      display: flex;
      justify-content: center;
      align-items: center;
    }

    /* Khung chứa ép chạy trên GPU */
    #actor {
      position: absolute;
      width: 200px;
      height: 120px;
      will-change: transform;
    }

    /* CSS Keyframes cho chuyển động vây và đuôi */
    .tail {
      transform-origin: 400px 250px;
      animation: wag 1.5s ease-in-out infinite;
    }

    .fin {
      transform-origin: 300px 280px;
      animation: flap 2s ease-in-out infinite;
    }

    @keyframes wag {
      0%, 100% { transform: rotate(-10deg); }
      50% { transform: rotate(15deg); }
    }

    @keyframes flap {
      0%, 100% { transform: rotate(0deg); }
      50% { transform: rotate(15deg); }
    }
  </style>
</head>
<body>

  <!-- Khung đồ họa SVG -->
  <div id="actor">
    <svg viewBox="150 150 350 200" width="100%" height="100%">
      <!-- Đuôi cá -->
      <g class="tail">
        <path d="M380,250 L450,220 L450,280 Z" fill="#00f3ff" />
      </g>
      <!-- Thân cá -->
      <path d="M200,250 C200,200 300,180 380,220 C420,240 420,260 380,280 C300,320 200,300 200,250 Z" fill="#0284c7" />
      <!-- Vây cá -->
      <g class="fin">
        <path d="M280,270 L300,310 L320,270 Z" fill="#00f3ff" />
      </g>
    </svg>
  </div>

  <script>
    // JavaScript giả lập di chuyển mượt mà ở 60fps
    const actor = document.getElementById('actor');
    let posX = window.innerWidth / 2;
    let posY = window.innerHeight / 2;
    let angle = 0;

    function animate() {
      // Tạo quỹ đạo di chuyển dạng lượn sóng
      angle += 0.02;
      posX += Math.cos(angle) * 1.5;
      posY += Math.sin(angle * 2) * 0.8;

      // Sử dụng translate3d để kích hoạt tăng tốc GPU
      actor.style.transform = `translate3d(${posX}px, ${posY}px, 0)`;

      requestAnimationFrame(animate);
    }

    requestAnimationFrame(animate);
  </script>

</body>
</html>
