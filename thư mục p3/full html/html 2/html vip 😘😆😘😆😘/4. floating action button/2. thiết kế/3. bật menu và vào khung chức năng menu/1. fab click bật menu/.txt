Tổng quan cách làm

4 phần ghép lại:

1. HTML — 2 khối riêng biệt: <button class="fab"> (nút kích hoạt) và <div class="panel"> (khung hiện ra), không lồng nhau.
2. CSS FAB — position: fixed + border-radius: 50% + gradient + z-index cao.
3. CSS Panel — position: fixed + bo góc + shadow + mặc định ẩn bằng opacity: 0 + pointer-events: none; thêm class .open thì hiện.
4. JS — 2 hàm openPanel() / closePanel() toggle class; gắn vào sự kiện click FAB, click X, ESC, click ngoài.

Nguyên lý chính (suy luận có căn cứ):

· Toggle class thay vì set style trực tiếp → CSS tự lo transition.
· opacity + transform + transition cho panel → mở/đóng mượt.
· pointer-events: none/auto — chặn click khi panel ẩn, cho click khi hiện.
· z-index cao cho FAB/panel → luôn nổi trên nội dung.

Tôi không chắc:

· Bạn muốn FAB ẩn khi panel mở (kiểu "FAB hidden on open") hay vẫn hiện — code dưới đây để FAB vẫn hiện theo mô tả "click FAB mở panel".
· Bạn muốn panel ở góc nào — mình để góc dưới-phải, gần FAB.

```js
(function () {
  const fab      = document.getElementById('fab');
  const panel    = document.getElementById('panel');
  const closeBtn = document.getElementById('closeBtn');
  const closeFooter = panel.querySelector('.close-footer');

  // ---- 2 hàm chuyển trạng thái ----
  function openPanel()  { panel.classList.add('open'); }
  function closePanel() { panel.classList.remove('open'); }

  // ---- Gắn sự kiện ----
  fab.addEventListener('click', openPanel);
  closeBtn.addEventListener('click', closePanel);
  closeFooter.addEventListener('click', closePanel);

  document.addEventListener('keydown', (e) => {
    if (e.key === 'Escape') closePanel();
  });

  // Click ngoài panel + FAB → đóng
  document.addEventListener('click', (e) => {
    if (!panel.contains(e.target) && !fab.contains(e.target)) {
      closePanel();
    }
  });
})();
```

---

Luồng chạy

```
ĐÓNG (mặc định)
  FAB: hiện  |  Panel: ẩn (opacity 0, pointer-events none)
       │
       │  click FAB
       ▼
MỞ
  FAB: hiện  |  Panel: hiện (opacity 1, pointer-events auto)
       │
       │  click X / Đóng / ESC / click ngoài
       ▼
ĐÓNG (quay lại ban đầu)
```

Tinh chỉnh nhanh

Muốn Sửa
Đổi vị trí panel right/bottom của .panel
Đổi màu panel background của .panel
Panel rộng hơn width: 300px → 400px
Bỏ click-ngoài-để-đóng Xóa block document.addEventListener('click', ...)
Ẩn FAB khi mở panel Trong openPanel() thêm fab.classList.add('is-hidden') + CSS .is-hidden { visibility: hidden; pointer-events: none; }
Đổi tốc độ mở/đóng transition ở .panel
