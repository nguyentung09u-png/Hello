Tổng quan cách làm

4 phần ghép lại:

1. HTML — 1 <button class="card-close" type="button">✕ Đóng menu</button> đặt trong footer của card.
2. CSS nút — width: 100% + padding + bo góc + màu xám mặc định.
3. CSS trạng thái — :hover đổi sang đỏ nhạt + :active scale nhẹ + transition .18s.
4. JS — 1 dòng addEventListener('click', ...) → card.classList.add('is-closed').

Nguyên lý chính (suy luận có căn cứ):

· width: 100% — nút chiếm hết chiều ngang footer.
· :hover — CSS pseudo-class, đổi style khi con trỏ lên nút.
· :active — pseudo-class, đổi style khi đang nhấn.
· transition — CSS làm mượt thay đổi giữa các trạng thái.
· classList.add('is-closed') — thêm class để CSS tự ẩn card (không cần set style trực tiếp trong JS).

Tôi không chắc:

· Bạn muốn nút trong footer hay ngoài card — code dưới để trong footer.
· Bạn muốn khi đóng thì ẩn hẳn hay có thể mở lại — code dưới ẩn hẳn, có thể thêm nút mở lại.

Code chung chung

```html
<div class="card" id="card">
  <div class="card-header">Menu</div>
  <div class="card-body">
    <p>Nội dung…</p>
  </div>
  <div class="card-footer">
    <button class="card-close" id="cardClose" type="button">
      ✕ Đóng menu
    </button>
  </div>
</div>
```

```css
/* ===== Card + trạng thái đóng ===== */
.card {
  width: 300px;
  background: #0f1729;
  color: #e8e0ff;
  border: 1px solid rgba(16,185,129,.25);
  border-radius: 16px;
  overflow: hidden;
  transition: opacity .25s ease, transform .25s ease;   /* cho animation đóng */
}
.card.is-closed {
  opacity: 0;
  transform: translateY(12px) scale(.96);
  pointer-events: none;
}

.card-header { padding: 12px 14px; background: linear-gradient(135deg,#10b981,#059669); color: #fff; font-weight: 600; }
.card-body   { padding: 16px 14px; font-size: 13.5px; line-height: 1.55; }
.card-footer { padding: 12px 14px; border-top: 1px solid rgba(255,255,255,.08); }

/* ===== Nút đóng ===== */
.card-close {
  width: 100%;                         /* full width */
  padding: 10px 14px;                  /* đệm trong */
  border: 1px solid rgba(255,255,255,.12);
  border-radius: 10px;                 /* bo góc */
  background: rgba(255,255,255,.06);   /* màu mặc định — xám nhẹ */
  color: #c8c1de;
  font-family: inherit;
  font-weight: 600;
  font-size: 13px;
  cursor: pointer;
  display: inline-flex;
  align-items: center;
  justify-content: center;
  gap: 6px;
  transition: background .18s ease, color .18s ease,
              border-color .18s ease, transform .18s ease;
}

/* Hover — đổi sang đỏ nhạt */
.card-close:hover {
  background: rgba(239, 68, 68, .18);
  border-color: rgba(239, 68, 68, .5);
  color: #ff8f8f;
  transform: translateY(-1px);
}

/* Active — nhấn xuống nhẹ */
.card-close:active {
  transform: translateY(0) scale(.98);
}

/* Reduced motion */
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation: none !important;
    transition: none !important;
  }
}
```

```js
(function () {
  const card = document.getElementById('card');
  const btn  = document.getElementById('cardClose');
  if (!card || !btn) return;

  btn.addEventListener('click', () => {
    card.classList.add('is-closed');
  });
})();
```

---

Tinh chỉnh nhanh

Muốn Sửa
Đổi text Sửa nội dung <button>✕ Đóng menu</button>
Đổi màu hover background / color trong .card-close:hover
Bỏ animation đóng Xóa transition ở .card, dùng card.style.display = 'none'
Ẩn hẳn ngay, không fade card.classList.add('is-closed') → card.style.display = 'none'
Thêm nút mở lại Thêm nút ngoài, click → card.classList.remove('is-closed')
Nút nằm ngoài card Chuyển <button> ra ngoài </div> của .card, thêm margin-top: 12px

Lưu ý (phân biệt rõ):

· Suy luận có căn cứ: width: 100% + :hover + :active + transition là CSS chuẩn; classList.add là DOM API chuẩn.
· Tôi không chắc bạn muốn nút trong footer hay ngoài card — code trên để trong footer.
· Tôi không chắc bạn muốn khi đóng thì ẩn hẳn hay có thể mở lại — code trên ẩn hẳn; có thể thêm nút mở lại nếu cần.
