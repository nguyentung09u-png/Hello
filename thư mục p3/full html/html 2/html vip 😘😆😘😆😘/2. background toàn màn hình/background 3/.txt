Tổng quan cách làm

Gồm 3 lớp chồng nhau:

1. Nền — gradient dọc trên body: tối → xanh đêm → đen.
2. Glow — <div class="glow-base"> với 2 radial-gradient + filter: blur(40px) để tạo ánh sáng nền.
3. Canvas hạt — <canvas> chạy requestAnimationFrame, mỗi frame cập nhật vị trí hạt và vẽ lại.

Nguyên lý hạt:

· Mỗi hạt có x, y, r, vy (âm = bay lên), vx, sway, life, maxLife.
· Mỗi frame: y += vy, x += vx + sin(sway) * 0.4, life += 1/60.
· Độ mờ fade = 1 - life / maxLife → càng già càng mờ.
· Khi life > maxLife hoặc hạt bay khỏi mép trên → tái sinh ở đáy màn.
· Nếu r > 1.6 → vẽ thêm halo bằng createRadialGradient.

Tối ưu (suy luận có căn cứ):

· DPR cap ở 2 → nét trên retina mà không quá nặng.
· visibilitychange → dừng khi tab ẩn.
· prefers-reduced-motion → không chạy vòng lặp.
· Số hạt tính theo W/12, cap 140.

Tôi không chắc:

· Fade tuyến tính (1 - life/maxLife) có đẹp bằng fade theo hàm mũ hay không — cần thử nhiều profile.
· Hiệu năng khi số hạt lên trên 200 — hiện chưa kiểm chứng.

```js
(function () {
  const c = document.getElementById('c');
  const ctx = c.getContext('2d');
  if (!ctx) return;

  const reduceMotion = matchMedia('(prefers-reduced-motion: reduce)').matches;

  let W = 0, H = 0, dpr = 1, rafId = 0;
  let parts = [];

  const COLORS = ['#7ab8ff','#a8c8ff','#c8a0ff','#8fd8ff','#b0c0ff','#e0b8ff'];

  function count() {
    return Math.min(140, Math.max(50, Math.floor(W / 12)));
  }

  function make(anywhere) {
    const r = Math.random() * 2.2 + 0.6;
    return {
      x: Math.random() * W,
      y: anywhere ? Math.random() * H : H + 20,
      r,
      vy: -(0.3 + Math.random() * 0.9),
      vx: (Math.random() - 0.5) * 0.4,
      sway: Math.random() * Math.PI * 2,
      swaySpeed: 0.4 + Math.random() * 0.8,
      color: COLORS[(Math.random() * COLORS.length) | 0],
      glow: r > 1.6,
      life: 0,
      maxLife: 6 + Math.random() * 6,
    };
  }

  function resize() {
    dpr = Math.min(window.devicePixelRatio || 1, 2);
    W = window.innerWidth;
    H = window.innerHeight;
    c.width  = W * dpr;
    c.height = H * dpr;
    c.style.width  = W + 'px';
    c.style.height = H + 'px';
    ctx.setTransform(dpr, 0, 0, dpr, 0, 0);

    const need = count();
    while (parts.length < need) parts.push(make(true));
    if (parts.length > need) parts.length = need;
  }

  function draw(t) {
    ctx.clearRect(0, 0, W, H);

    for (let i = 0; i < parts.length; i++) {
      const p = parts[i];
      p.life += 1 / 60;
      p.sway += 0.03 * p.swaySpeed;
      p.x += p.vx + Math.sin(p.sway) * 0.4;
      p.y += p.vy;

      const fade = Math.max(0, 1 - p.life / p.maxLife);
      const alpha = 0.7 * fade;

      if (p.life > p.maxLife || p.y < -20) {
        parts[i] = make(false);
        continue;
      }

      if (p.glow) {
        const g = ctx.createRadialGradient(p.x, p.y, 0, p.x, p.y, p.r * 8);
        g.addColorStop(0,   p.color + 'cc');
        g.addColorStop(0.4, p.color + '44');
        g.addColorStop(1,   p.color + '00');
        ctx.fillStyle = g;
        ctx.beginPath();
        ctx.arc(p.x, p.y, p.r * 8, 0, Math.PI * 2);
        ctx.fill();
      }

      ctx.beginPath();
      ctx.fillStyle = p.color;
      ctx.globalAlpha = alpha;
      ctx.arc(p.x, p.y, p.r, 0, Math.PI * 2);
      ctx.fill();
    }

    ctx.globalAlpha = 1;
    rafId = requestAnimationFrame(draw);
  }

  function start() { if (!rafId && !reduceMotion) rafId = requestAnimationFrame(draw); }
  function stop()  { if (rafId) { cancelAnimationFrame(rafId); rafId = 0; } }

  window.addEventListener('resize', resize, { passive: true });
  document.addEventListener('visibilitychange', () => {
    if (document.hidden) stop();
    else start();
  });

  resize();
  start();
})();
```

Lưu ý (phân biệt rõ):

· Suy luận có căn cứ: code dùng Canvas 2D + requestAnimationFrame, chạy được trên trình duyệt hiện đại có canvas.
· Tôi không chắc fade tuyến tính là tối ưu — có thể thử Math.pow(fade, 1.5) cho mượt hơn.
· Tôi không chắc hiệu năng khi vượt 200 hạt — hiện đã giới hạn ở 140 để an toàn.

🎯 Tóm 1 câu: Nền gradient dọc + lớp glow blur + canvas hạt bay lên có halo (vẽ bằng createRadialGradient + arc), fade theo tuổi, tái sinh ở đáy — chạy requestAnimationFrame với DPR cap, visibilitychange, prefers-reduced-motion.
