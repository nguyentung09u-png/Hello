
(Ripple + Squash & Stretch + Glow pulse)

Tóm gọn quy trình 3 hiệu ứng

---

BƯỚC 0 — Xác định vai trò

· Ripple → phản hồi điểm click
· Squash & Stretch → nén khi nhấn, bung khi active
· Glow Pulse → vòng sáng xác nhận active

---

BƯỚC 1 — Chọn kênh

· Ripple → JS tạo element + CSS animate
· Squash & Stretch → CSS thuần
· Glow Pulse → CSS thuần (::after)

---

BƯỚC 2 — CSS từng hiệu ứng

```css
/* Ripple */
.ripple {
  position: absolute;
  border-radius: 50%;
  transform: scale(0);
  animation: ripple 0.6s ease-out;
}
@keyframes ripple { to { transform: scale(20); opacity: 0; } }

/* Squash & Stretch */
.btn:active { transform: scale(0.94); }
.btn.active { animation: pop 0.5s cubic-bezier(0.22,1,0.36,1); }
@keyframes pop {
  0%   { transform: translateY(0) scale(1); }
  40%  { transform: translateY(-12px) scale(1.05); }
  100% { transform: translateY(-8px) scale(1); }
}

/* Glow Pulse */
.btn.active::after {
  content: '';
  position: absolute;
  inset: -4px;
  border: 2px solid #60a5fa;
  border-radius: inherit;
  animation: pulse 1.2s ease-out;
}
@keyframes pulse {
  0%   { transform: scale(1); opacity: 0.8; }
  100% { transform: scale(1.3); opacity: 0; }
}
```

---

BƯỚC 3 — JS

```js
btn.onclick = (e) => {
  // Ripple
  const r = document.createElement('span');
  r.className = 'ripple';
  r.style.left = e.offsetX + 'px';
  r.style.top  = e.offsetY + 'px';
  btn.appendChild(r);
  r.onanimationend = () => r.remove();

  // Toggle active (cho Squash + Glow)
  if (activeButton) activeButton.classList.remove('active');
  btn.classList.add('active');
  activeButton = btn;
};
```

---

BƯỚC 4 — Ghép nhịp

· Ripple: 0.6s
· Squash: 0.1s
· Pop: 0.5s
· Glow: 1.2s

→ Chạy theo thứ tự: ripple → squash → pop → glow

---

BƯỚC 5 — Test

· Spam click → ripple tự xóa
· Đổi nút → xóa active cũ
· Toggle off → ripple vẫn chạy
· Reduced motion → tắt animation

---

TÓM 1 DÒNG

```
Ripple (JS+CSS) + Squash (:active + keyframes) + Glow (::after + keyframes)
→ JS chỉ tạo ripple và toggle class, CSS lo toàn bộ chuyển động
```
