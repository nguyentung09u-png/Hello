Cách làm Stack / Deck: xếp các card chồng lên nhau bằng position: absolute, card trên cùng có z-index cao nhất. Khi lật, card trên cùng bay ra rồi đưa xuống cuối mảng.

---

Code chung

CSS — xếp chồng:

```css
.card {
  position: absolute;
  top: 0; left: 0;
  width: 100%; height: 100%;
  transition: transform 0.5s ease;
}
.card.behind-1 { transform: translateY(15px) scale(0.95); z-index: 99; }
.card.behind-2 { transform: translateY(30px) scale(0.90); z-index: 98; }
.card.top      { z-index: 100; }
```

JS — lật bài:

```js
function nextCard() {
  const top = cards[0];

  // Bay ra
  top.style.transform = 'translateX(400px) rotate(30deg)';

  // Đợi 1s rồi đưa xuống cuối
  setTimeout(() => {
    cards.push(cards.shift());
    cards.forEach(c => c.style.transform = '');
    updateStack();
  }, 1000);
}
```

JS — cập nhật vị trí:

```js
function updateStack() {
  cards.forEach((card, i) => {
    card.className = 'card';
    if (i === 0) card.classList.add('top');
    else if (i === 1) card.classList.add('behind-1');
    else if (i === 2) card.classList.add('behind-2');
  });
}
```

---

Lưu ý

· Kéo để lật: thêm mousedown/touchstart → tính khoảng cách kéo → nếu vượt ngưỡng thì gọi nextCard().
· Tôi không chắc hiệu ứng mượt trên mobile cũ — cần test thực tế.
· Muốn nhiều card hiển thị hơn → thêm class behind-3, behind-4...
· Đợi 1 giây trước khi lật → setTimeout(..., 1000).
