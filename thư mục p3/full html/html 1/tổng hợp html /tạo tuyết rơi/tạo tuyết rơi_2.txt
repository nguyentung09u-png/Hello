1. tạo tuyết

6 bước này để tạo ra tuyết đúng


Bước 1 — Khởi tạo

Chức năng: Tạo một hạt tuyết với thuộc tính ngẫu nhiên.
Cách làm: Constructor nhận (w, h, opts), gọi reset(true, opts) để khởi tạo ngay.

Bước 2 — reset(randomY, opts)

Chức năng: Đặt lại toàn bộ thuộc tính hạt (dùng khi tạo mới hoặc tái sinh).
Cách làm:

1. Lấy cấu hình từ opts: minR/maxR, minSpeed/maxSpeed, minAlpha/maxAlpha, colorBase.
2. radius = ngẫu nhiên trong [minR, maxR].
3. x = ngẫu nhiên trong [0, w].
4. y = nếu randomY thì ngẫu nhiên trong [0, h], ngược lại đặt phía trên màn hình (-10 - random*20).
5. speedY = tốc độ rơi ngẫu nhiên.
6. alpha = độ mờ ngẫu nhiên.
7. sway = pha dao động ban đầu ngẫu nhiên.
8. swaySpeed = tốc độ đổi pha (0.005–0.02).
9. swayAmp = biên độ lắc ngang (0.2–1.0).
10. Màu: t = colorBase + random(0..20) → r = t, g = t+5, b = 255.

Kết quả: Một hạt có vị trí, kích thước, tốc độ, độ mờ, dao động và màu riêng.

Bước 3 — step()

Chức năng: Cập nhật vị trí hạt mỗi frame.
Cách làm:

1. y += speedY → rơi xuống.
2. sway += swaySpeed → tiến pha dao động.
3. x += sin(sway) * swayAmp * 0.3 → lắc ngang nhẹ.
4. Nếu y > h+20 hoặc x ra ngoài [-30, w+30] → gọi reset(false) để tái sinh từ trên đỉnh.

Kết quả: Hạt rơi xuống, lắc lư, và tự tái sinh khi ra khỏi màn hình.

Bước 4 — draw(ctx, blend)

Chức năng: Vẽ hạt lên canvas.
Cách làm:

1. Đặt globalCompositeOperation = blend (mặc định source-over).
2. beginPath() → arc(x, y, radius, 0, 2π).
3. fillStyle = rgba(r, g, b, alpha).
4. fill().
5. Trả globalCompositeOperation về source-over.

Kết quả: Một chấm tròn xanh-trắng mờ ảo xuất hiện trên canvas.

Bước 5 — Hàm setupCanvas(canvas)

Chức năng: Chuẩn bị canvas nét trên mọi màn hình.
Cách làm:

1. dpr = min(devicePixelRatio, 2).
2. Đo rect = canvas.getBoundingClientRect().
3. Gán canvas.width = rect.width * dpr, canvas.height = rect.height * dpr.
4. ctx.scale(dpr, dpr).
   Kết quả: Trả về { ctx, w, h } — context đã scale đúng.

Bước 6 — Vòng lặp

Cách làm: Trong draw() của mỗi card, gọi f.step() rồi f.draw(ctx, blend) cho từng hạt, sau đó requestAnimationFrame(draw).

🔢 Công thức tạo 100 hạt — từng bước

Bước A — Khai báo số hạt cố định

```
CONFIG.count = 100
```

Bước B — Công thức tạo mảng

```
count = CONFIG.count          // = 100
flakes = new Array(count)     // mảng 100 phần tử
```

Bước C — Vòng lặp tạo từng hạt

```
for i = 0 → count-1:
    flakes[i] = new Flake(w, h, CONFIG)
```

Bước D — Mỗi hạt random thuộc tính (bước 2 gốc)

```
radius    = rand(minR, maxR)          ∈ [0.8, 3.2]
x         = rand(0, w)
y         = rand(0, h)  hoặc  -10-rand(0,20)
speedY    = rand(minSpeed, maxSpeed)  ∈ [0.6, 2.4]
alpha     = rand(minAlpha, maxAlpha)  ∈ [0.4, 1.0]
sway      = rand(0, 2π)
swaySpeed = rand(0.005, 0.02)
swayAmp   = rand(0.2, 1.0)
màu       = (colorBase + rand(0,20), +5, 255)
```

Bước E — Kết quả

```
Tổng hạt = 100 (luôn luôn)
Mọi màn hình → vẫn 100 hạt
Resize       → vẫn 100 hạt
Tái sinh     → vẫn giữ đủ 100 hạt

Thêm hiệu ứng Blend lighter + Glow

Bước 1 — Bật chế độ hòa trộn lighter

Chức năng: Khi các hạt chồng lên nhau, màu sẽ cộng dồn thay vì đè → vùng chồng sáng hơn.
Cách làm: Trước vòng lặp vẽ hạt, đặt:

```js
ctx.globalCompositeOperation = 'lighter';
```

Kết quả: Nền tối + nhiều hạt gần nhau → tạo thành đốm sáng rực.

---

Bước 2 — Vẽ quầng glow ngoài (radial gradient)

Chức năng: Tạo vầng sáng mềm lan tỏa quanh hạt.
Cách làm:

1. Tạo gradient tâm tại (f.x, f.y), bán kính 0 → f.radius * 4.
2. Thêm 3 điểm dừng màu:
   · 0 → rgba(r, g, 255, alpha * 0.6) — sáng nhất ở lõi.
   · 0.4 → rgba(r, g, 255, alpha * 0.15) — mờ dần.
   · 1 → rgba(120, 180, 255, 0) — trong suốt hoàn toàn.
3. arc(f.x, f.y, f.radius * 4) + fill().

Kết quả: Mỗi hạt có một quầng sáng xanh mờ bao quanh, lan rộng gấp 4 lần bán kính.

---

Bước 3 — Vẽ lõi hạt sáng

Chức năng: Tạo điểm sáng trắng ở tâm hạt.
Cách làm:

```js
ctx.beginPath();
ctx.arc(f.x, f.y, f.radius, 0, Math.PI * 2);
ctx.fillStyle = `rgba(255, 255, 255, ${f.alpha})`;
ctx.fill();
```

Kết quả: Lõi trắng nổi bật trên nền quầng xanh, tạo cảm giác "ngôi sao nhỏ".

---

Bước 4 — Vẽ tia sáng cho hạt lớn

Chức năng: Hạt to (radius > 2.2) có thêm 4 tia ngang/dọc → lấp lánh như tinh thể.
Cách làm:

1. len = f.radius * 2.2.
2. strokeStyle = rgba(200, 230, 255, alpha * 0.5), lineWidth = 0.6.
3. Vẽ 2 đường:
   · Ngang: (x-len, y) → (x+len, y)
   · Dọc: (x, y-len) → (x, y+len)

Kết quả: Hạt lớn trở thành "ngôi sao 4 cánh" mờ, tăng cảm giác lấp lánh.

---

Bước 5 — Khôi phục chế độ vẽ

Chức năng: Tránh ảnh hưởng frame sau / các phần vẽ khác.
Cách làm: Sau vòng lặp:

```js
ctx.globalCompositeOperation = 'source-over';
```

Kết quả: clearRect frame sau hoạt động đúng, không bị cộng dồn vĩnh viễn.

---

Bước 6 — Vòng lặp render

Cách làm:

```
clearRect → bật 'lighter'
  → với mỗi hạt:
      step()
      vẽ quầng glow (gradient)
      vẽ lõi trắng
      nếu radius > 2.2 → vẽ 4 tia
→ tắt 'lighter' → requestAnimationFrame
```

Thêm hiệu ứng Gió sin theo thời gian

Bước 1 — Khai báo biến thời gian

Chức năng: Lưu mốc thời gian để tính gió.
Cách làm: Khai báo let time = 0; ngoài hàm draw(), reset về 0 trong init().
Kết quả: Có biến tích lũy thời gian qua các frame.

---

Bước 2 — Hàm windStrength(t) — cường độ gió

Chức năng: Tính sức gió tại thời điểm t bằng tổng 2 sóng sin.
Cách làm:

```js
function windStrength(t) {
    return Math.sin(t * 0.0006) * 0.8
         + Math.sin(t * 0.0017 + 1.3) * 0.4;
}
```

· Sóng 1: tần số chậm (0.0006), biên độ 0.8 → gió chính.
· Sóng 2: tần số nhanh hơn (0.0017), biên độ 0.4, lệch pha 1.3 → gợn phụ.
· Cộng lại → gió đổi chiều mượt mà, không tuần hoàn đơn điệu.

Kết quả: Giá trị gió dao động khoảng [-1.2, +1.2], âm = bay trái, dương = bay phải.

---

Bước 3 — Cập nhật thời gian mỗi frame

Chức năng: Tăng time đều đặn để gió tiến hóa.
Cách làm: Trong draw():

```js
time += 16; // ~16ms/frame ≈ 60fps
const wind = windStrength(time);
```

Kết quả: Mỗi frame gió có giá trị mới, mượt theo thời gian thực.

---

Bước 4 — Tính hệ số gió cho từng hạt

Chức năng: Hạt nhỏ (nhẹ) bay xa hơn, hạt to (nặng) bay ít hơn.
Cách làm:

```js
const windFactor = (4 - f.radius) * 0.4;
```

· radius nhỏ (≈1) → windFactor ≈ 1.2 (bay mạnh).
· radius lớn (≈3.8) → windFactor ≈ 0.08 (gần như đứng yên).

Kết quả: Đàn tuyết phân tầng theo kích thước, tạo chiều sâu tự nhiên.

---

Bước 5 — Cập nhật vị trí hạt (thay cho step() mặc định)

Chức năng: Kết hợp rơi + gió + dao động tại chỗ.
Cách làm: Với mỗi hạt:

```js
f.sway += f.swaySpeed;          // tiến pha dao động
f.y += f.speedY;                // rơi xuống
f.x += wind * windFactor;       // gió đẩy ngang
f.x += Math.sin(f.sway) * f.swayAmp * 0.2;  // lắc nhẹ tại chỗ
```

Kết quả: Hạt vừa rơi, vừa trôi theo gió, vừa run nhẹ.

---

Bước 6 — Tái sinh hạt

Chức năng: Đưa hạt về đỉnh khi ra khỏi màn hình.
Cách làm:

```js
if (f.y > h + 20 || f.x < -40 || f.x > w + 40) {
    f.reset(false, CONFIG);
}
```

· Kiểm tra cả 3 cạnh: dưới, trái, phải (vì gió có thể đẩy hạt ra hai bên).
  Kết quả: Đàn tuyết luôn đầy đủ, không bị "mất hạt" ở rìa.

---

Bước 7 — Vẽ hạt

Cách làm:

```js
ctx.beginPath();
ctx.arc(f.x, f.y, f.radius, 0, Math.PI * 2);
ctx.fillStyle = `rgba(${f.r}, ${f.g}, ${f.b}, ${f.alpha})`;
ctx.fill();
```

Kết quả: Hạt hiển thị đúng vị trí mới sau khi cập nhật.

---

Bước 8 — Vòng lặp render

Cách làm:

```
clearRect
  → time += 16
  → wind = windStrength(time)
  → với mỗi hạt:
      cập nhật sway, y, x (gió + lắc)
      tái sinh nếu ra ngoài
      vẽ
  → requestAnimationFrame
```
