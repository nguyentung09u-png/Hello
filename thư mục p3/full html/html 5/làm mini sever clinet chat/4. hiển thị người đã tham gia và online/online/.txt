Tổng quan cách làm (ngắn)

Theo cách tôi hiểu, để làm ô "● N online" cần 3 khối:

1. HTML + CSS — dựng khung viên thuốc xanh nhạt (3 span: chấm, số, chữ), chấm nhấp nháy bằng @keyframes pulse.
2. Firebase Presence — mỗi client tự ghi mình vào node presence/{userId} khi kết nối, và dùng onDisconnect().remove() để tự xóa khi offline.
3. JS đếm — onValue(presence) để lắng nghe, đếm Object.keys(data).length, gán vào #online-count.

Lưu ý: tôi không chắc Firebase xử lý onDisconnect giống nhau trong mọi tình huống mạng — theo tôi biết nó dựa vào việc server phát hiện mất kết nối, có thể trễ vài giây.

---

Code chung chung (minimal demo)

```html
<!DOCTYPE html>
<html>
<head>
<meta charset="UTF-8" />
<style>
  body{ margin:0; padding:40px;
        background:#02030a; color:#fff;
        font-family:system-ui,sans-serif; }

  /* khung viên thuốc */
  .status{
    display:inline-flex; align-items:center; gap:6px;
    font-size:.85rem; font-weight:500;
    background:#ECFDF5; color:#059669;
    padding:4px 10px; border-radius:20px;
  }

  /* chấm xanh nhấp nháy */
  .status-dot{
    width:8px; height:8px; border-radius:50%;
    background:#10B981; box-shadow:0 0 8px #10B981;
    animation:pulse 2s infinite;
  }
  @keyframes pulse{
    0%  { transform:scale(.95); box-shadow:0 0 0 0 rgba(16,185,129,.7); }
    70% { transform:scale(1);   box-shadow:0 0 0 6px rgba(16,185,129,0); }
    100%{ transform:scale(.95); box-shadow:0 0 0 0 rgba(16,185,129,0); }
  }
</style>
</head>
<body>

  <div class="status">
    <span class="status-dot"></span>
    <span id="online-count">0</span>
    online
  </div>

  <!-- Firebase SDK v9 -->
  <script type="module">
    import { initializeApp } from "https://www.gstatic.com/firebasejs/9.22.0/firebase-app.js";
    import {
      getDatabase, ref, onValue, set, onDisconnect, serverTimestamp
    } from "https://www.gstatic.com/firebasejs/9.22.0/firebase-database.js";

    // ⚠️ thay config của bạn
    const firebaseConfig = {
      databaseURL: "https://chat-d878c-default-rtdb.asia-southeast1.firebasedatabase.app"
    };

    const app = initializeApp(firebaseConfig);
    const db  = getDatabase(app);

    // ID tạm cho client (demo)
    const userId   = 'user_' + Math.random().toString(36).substring(2, 9);
    const userName = 'Khách';

    const onlineCountEl = document.getElementById('online-count');

    // 1. Báo online khi kết nối
    onValue(ref(db, '.info/connected'), snap => {
      if (snap.val() === true){
        const myRef = ref(db, `presence/${userId}`);
        set(myRef, { name: userName, onlineAt: serverTimestamp() });
        onDisconnect(myRef).remove();   // tự xóa khi offline
      }
    });

    // 2. Đếm số người online
    onValue(ref(db, 'presence'), snapshot => {
      const data = snapshot.val();
      onlineCountEl.innerText = data ? Object.keys(data).length : "0";
    });
  </script>
</body>
</html>
```

Giải thích ngắn:

· .status — khung viên thuốc xanh mint, chứa 3 span.
· .status-dot — chấm tròn 8px + @keyframes pulse → nhấp nháy 2s/lần.
· JS gồm 2 listener: một cho .info/connected (báo online), một cho presence (đếm và cập nhật số).

Lưu ý:

· Code trên cần chạy qua Live Server hoặc hosting vì dùng ES Modules (type="module").
· Để test nhiều client, mở nhiều tab ẩn danh — mỗi tab là 1 userId khác nhau.
· Tôi không chắc onDisconnect luôn chạy đúng trong mọi điều kiện mạng — đôi khi có độ trễ.
