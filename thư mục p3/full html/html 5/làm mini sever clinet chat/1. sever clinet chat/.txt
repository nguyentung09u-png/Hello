Tổng quan cách làm (ngắn)

Theo code chúng ta đã viết, kết nối Firebase cần 5 bước theo thứ tự:

1. firebaseConfig — object chứa databaseURL (bắt buộc với Realtime DB).
2. initializeApp() — đăng ký dự án với SDK.
3. getDatabase() — lấy handle db để thao tác.
4. ref(db, 'path') — tạo địa chỉ trỏ tới node cần làm việc.
5. push/set/remove (ghi) và onValue/query (đọc realtime).

Lưu ý: tôi không chắc bạn đang dùng SDK v8 hay v9 — code dưới dùng v9 modular. V8 (compat) cú pháp khác hoàn toàn.

---

Code chung chung (minimal demo)

```html
<!DOCTYPE html>
<html>
<head>
<meta charset="UTF-8" />
</head>
<body>

  <button id="btn-send">Gửi tin demo</button>
  <div id="log"></div>

  <script type="module">
    // 1. IMPORT SDK
    import { initializeApp } from "https://www.gstatic.com/firebasejs/9.22.0/firebase-app.js";
    import {
      getDatabase, ref, push, onValue, query, limitToLast,
      serverTimestamp
    } from "https://www.gstatic.com/firebasejs/9.22.0/firebase-database.js";

    // 2. CONFIG
    const firebaseConfig = {
      databaseURL: "https://chat-d878c-default-rtdb.asia-southeast1.firebasedatabase.app"
    };

    // 3. KHỞI TẠO
    const app = initializeApp(firebaseConfig);
    const db  = getDatabase(app);

    // 4. TẠO REF
    const messagesRef = ref(db, 'messages');

    // 5. GHI — push 1 tin demo
    document.getElementById('btn-send').onclick = () => {
      push(messagesRef, {
        userId:    'demo_user',
        name:      'Demo',
        text:      'Xin chào',
        timestamp: serverTimestamp(),
        isSystem:  false
      });
    };

    // 6. ĐỌC — lắng nghe 20 tin mới nhất
    const log = document.getElementById('log');
    onValue(query(messagesRef, limitToLast(20)), snapshot => {
      log.innerHTML = '';
      snapshot.forEach(child => {
        const m = child.val();
        const line = document.createElement('div');
        line.textContent = `${m.name}: ${m.text}`;
        log.appendChild(line);
      });
    });
  </script>
</body>
</html>
```

Giải thích ngắn:

· 3 dòng đầu: import SDK.
· firebaseConfig — phải đúng databaseURL của dự án.
· initializeApp + getDatabase — mở kết nối.
· ref(db, 'messages') — trỏ vào node messages.
· push() — gửi tin lên server.
· onValue(query(...)) — lắng nghe realtime và render.

Lưu ý:

· Cần chạy qua Live Server hoặc hosting (vì ES Modules).
· Node messages không cần tạo trước — push() sẽ tự sinh.
· Tôi không chắc Rules của dự án bạn cho phép đọc/ghi mặc định — có thể phải vào Console chỉnh.
· 5 field trong object là do code đặt, không phải Firebase bắt buộc.
