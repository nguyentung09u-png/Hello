Full tổng quan: Nút xóa + Trang xóa lịch sử được làm từ gì

Theo code chúng ta đã viết, tính năng này gồm 4 thành phần:

---

1. HTML — 2 phần tách biệt

a) Nút xóa trên header:

```html
<button class="btn-icon danger" id="clear-btn" title="Xóa lịch sử">
  <svg width="16" height="16" viewBox="0 0 24 24" ...>
    <polyline points="3 6 5 6 21 6"/>
    <path d="M19 6l-1 14a2 2 0 0 1-2 2H8a2 2 0 0 1-2-2L5 6"/>
    <path d="M10 11v6M14 11v6"/>
    <path d="M9 6V4a1 1 0 0 1 1-1h4a1 1 0 0 1 1 1v2"/>
  </svg>
</button>
```

· Dùng SVG inline vẽ icon thùng rác (4 path: nắp, thân, 2 vạch dọc, quai).

b) Trang xác nhận full-screen:

```html
<div class="clear-page" id="clear-page">
  <div class="clear-page-inner">
    <div class="clear-icon"><svg>...</svg></div>
    <h2>Xóa tất cả lịch sử?</h2>
    <p>Hành động này sẽ xóa <strong>toàn bộ tin nhắn</strong>...</p>
    <div class="clear-actions">
      <button class="btn-cancel" id="clear-cancel">Hủy</button>
      <button class="btn-confirm" id="clear-confirm">Xóa hết</button>
    </div>
  </div>
</div>
```

2. CSS — 3 nhóm

a) Nút icon chung:

```css
.btn-icon{ background:none; border:none; cursor:pointer;
  padding:5px; border-radius:50%; transition:all .2s; }
.btn-icon.danger:hover{ color:var(--danger); background:rgba(239,68,68,.1); }
```

b) Trang phủ full-screen:

```css
.clear-page{
  position:fixed; inset:0; z-index:1000;
  display:flex; justify-content:center; align-items:center;
  background:rgba(8,10,20,.6);
  backdrop-filter:blur(16px); -webkit-backdrop-filter:blur(16px);
  opacity:0; visibility:hidden; pointer-events:none;
  transition:opacity .4s ease, visibility .4s;
}
.clear-page.open{ opacity:1; visibility:visible; pointer-events:auto; }
```

· Mặc định ẩn (opacity 0 + visibility hidden).
· Thêm class .open → hiện ra + fade.

c) Hộp thoại + hiệu ứng:

```css
.clear-page-inner{
  background:linear-gradient(160deg, rgba(30,27,75,.95), rgba(15,23,42,.95));
  border:1px solid rgba(239,68,68,.35);
  box-shadow:0 25px 60px -12px rgba(239,68,68,.35);
  transform:translateY(20px) scale(.95);   /* hơi nghiêng khi ẩn */
  transition:transform .4s cubic-bezier(.34,1.56,.64,1);  /* bật nảy */
}
.clear-page.open .clear-page-inner{ transform:translateY(0) scale(1); }

@keyframes shake{   /* icon thùng rác lắc nhẹ mỗi 2.5s */
  0%,90%,100%{ transform:rotate(0); }
  92%{ transform:rotate(-8deg); }
  94%{ transform:rotate(8deg); }
  96%{ transform:rotate(-6deg); }
  98%{ transform:rotate(6deg); }
}
```

· cubic-bezier(.34,1.56,.64,1) — easing "overshoot" → hộp thoại bật nảy khi mở.
· @keyframes shake — icon lắc đầu như đang cảnh báo.

3. JS — DOM + sự kiện

a) Mở/đóng trang:

```js
const clearPage = document.getElementById('clear-page');
const clearBtn  = document.getElementById('clear-btn');

clearBtn.addEventListener('click', () => clearPage.classList.add('open'));
clearCancel.addEventListener('click', () => clearPage.classList.remove('open'));

// Click ra ngoài overlay
clearPage.addEventListener('click', e => {
  if (e.target === clearPage) clearPage.classList.remove('open');
});

// Nhấn Esc
document.addEventListener('keydown', e => {
  if (!clearPage.classList.contains('open')) return;
  if (e.key === 'Escape') clearPage.classList.remove('open');
});
```

4. JS — Logic xóa Firebase

```js
clearConfirm.addEventListener('click', async () => {
  clearConfirm.disabled = true;
  clearConfirm.textContent = 'Đang xóa...';
  try {
    await remove(ref(db, 'messages'));   // xóa node messages
    await remove(ref(db, 'typing'));     // xóa node typing
    closeClearPage();

    // Gửi tin hệ thống báo đã xóa
    push(ref(db, 'messages'), {
      userId: 'system', name: 'Hệ thống',
      text: `🗑️ ${userName} đã xóa toàn bộ lịch sử phòng chat.`,
      timestamp: serverTimestamp(), isSystem: true
    });
  } catch (err){
    console.error(err);
    clearConfirm.textContent = 'Thử lại';
    alert('Không xóa được — kiểm tra Firebase Rules.');
  }
});
```

Logic chính:

· remove(ref(db, 'messages')) — xóa toàn bộ node messages (mọi người).
· Gửi tin hệ thống để thông báo.
· try/catch để bắt lỗi Rules.

---

Luồng hoạt động

```
Click nút 🗑️  → thêm class .open vào .clear-page
                     ↓
            Trang phủ hiện ra (fade + bật nảy)
                     ↓
            Nhấn "Xóa hết" → remove(messages) + remove(typing)
                     ↓
            Đóng trang + push tin hệ thống "đã xóa"
                     ↓
            onValue(messages) trigger → mọi client xóa chatBox
```

---

Lưu ý

· Firebase Rules phải cho phép xóa node messages — nếu không sẽ báo lỗi.
· Hàm xóa không phân quyền — ai cũng xóa được. Muốn giới hạn, cần kiểm tra userId trước khi cho mở trang.
· remove() xóa toàn bộ dữ liệu node, không thể hoàn tác.

---

🎯 Tóm 1 câu: Nút xóa là <button> chứa SVG thùng rác, trang xác nhận là .clear-page cố định full-screen (opacity 0 → thêm class .open để fade + bật nảy), JS mở/đóng bằng classList + xử lý click ra ngoài/Esc, còn logic xóa dùng remove(ref(db, 'messages')) + remove(ref(db, 'typing')) rồi push tin hệ thống "đã xóa".
