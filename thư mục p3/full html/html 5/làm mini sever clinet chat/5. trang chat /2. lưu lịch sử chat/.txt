Tổng quan cách làm (ngắn)

Theo cách tôi hiểu, để dùng node messages cần 3 bước:

1. Cấu hình Firebase — khởi tạo app + database bằng SDK v9.
2. Ghi tin — gọi push(ref(db, 'messages'), { 5 field }) khi người dùng gửi.
3. Đọc tin — gọi onValue(query(ref(db, 'messages'), limitToLast(50)), callback) để render realtime.

Lưu ý: tôi không chắc bạn đang dùng Firebase SDK phiên bản nào — code dưới dùng v9 (modular). Nếu bạn đang dùng v8 (compat), cú pháp sẽ khác.

---

Code chung chung (minimal demo)

```html
<!DOCTYPE html>
<html>
<head>
<meta charset="UTF-8" />
<style>
  body{ margin:0; padding:40px; background:#02030a; color:#fff;
        font-family:system-ui,sans-serif; }
  #box{ max-width:420px; display:flex; flex-direction:column; gap:8px; }
  .msg{ padding:8px 12px; border-radius:12px; background:#1e1b4b; }
  .sys{ text-align:center; font-style:italic; color:#6B7280; background:transparent; }
</style>
</head>
<body>

  <div id="box"></div>

  <script type="module">
    import { initializeApp } from "https://www.gstatic.com/firebasejs/9.22.0/firebase-app.js";
    import {
      getDatabase, ref, push, onValue, query, limitToLast,
      serverTimestamp
    } from "https://www.gstatic.com/firebasejs/9.22.0/firebase-database.js";

    // ⚠️ thay config của bạn
    const firebaseConfig = {
      databaseURL: "https://chat-d878c-default-rtdb.asia-southeast1.firebasedatabase.app"
    };

    const app = initializeApp(firebaseConfig);
    const db  = getDatabase(app);

    const box = document.getElementById('box');

    // dữ liệu demo
    const userId   = 'user_' + Math.random().toString(36).substring(2, 9);
    const userName = 'Khách ' + Math.floor(Math.random() * 100);

    // ---------- 1. GHI TIN ----------
    function sendMessage(text, isSystem = false){
      push(ref(db, 'messages'), {
        userId:   isSystem ? 'system' : userId,
        name:     isSystem ? 'Hệ thống' : userName,
        text:     text,
        timestamp: serverTimestamp(),
        isSystem: isSystem
      });
    }

    // demo: gửi 1 tin thường + 1 tin hệ thống
    setTimeout(() => sendMessage('Chào mọi người 👋'), 1000);
    setTimeout(() => sendMessage(`${userName} đã tham gia phòng chat.`, true), 2000);

    // ---------- 2. ĐỌC TIN ----------
    onValue(
      query(ref(db, 'messages'), limitToLast(50)),
      snapshot => {
        box.innerHTML = '';
        snapshot.forEach(child => {
          const m = child.val();   // { userId, name, text, timestamp, isSystem }
          const div = document.createElement('div');
          div.classList.add('msg');
          if (m.isSystem) div.classList.add('sys');
          div.textContent = m.isSystem ? m.text : `${m.name}: ${m.text}`;
          box.appendChild(div);
        });
      }
    );
  </script>
</body>
</html>
```

Giải thích ngắn:

· push(ref(db, 'messages'), obj) — thêm 1 child mới với key tự sinh, chứa 5 field.
· query(..., limitToLast(50)) — chỉ lấy 50 tin mới nhất.
· onValue(...) — lắng nghe realtime; mỗi khi có tin mới, callback chạy và render lại.
· serverTimestamp() — Firebase tự gán giờ server, tránh client sai giờ.

Lưu ý:

· Code cần chạy qua Live Server hoặc hosting (vì dùng ES Modules).
· Node messages là NoSQL — không cần tạo trước, push() sẽ tự tạo.
· Tôi không chắc Rules mặc định của Firebase cho phép đọc/ghi — bạn có thể cần vào Console chỉnh Rules.
· 5 field là do bạn tự định nghĩa, không phải Firebase bắt buộc.
