Tổng quan cách làm (ngắn)

Theo cách tôi hiểu, để bỏ mép đen và cho khung chat full màn hình cần 5 bước:

1. <meta viewport> — thêm viewport-fit=cover để cho phép tràn vào tai thỏ.
2. html, body — set width/height:100%, overflow:hidden, bỏ padding/flex cũ.
3. .app-container — đổi sang 100vw × 100dvh + position:fixed; inset:0.
4. Bỏ trang trí — border-radius:0, border:none, box-shadow:none.
5. env(safe-area-inset-*) — padding cho header/input để né tai thỏ và thanh điều hướng.

Lưu ý: tôi không chắc 100dvh và env() hỗ trợ trên mọi trình duyệt — theo tôi biết Safari iOS 15.4+ và Chrome 108+ mới có, bản cũ sẽ fallback về 100vh/0px.

---

Code chung chung (minimal demo)

```html
<!DOCTYPE html>
<html>
<head>
<meta charset="UTF-8" />
<meta name="viewport" content="width=device-width, initial-scale=1.0, viewport-fit=cover" />
<style>
  /* 1. Xóa mặc định html/body */
  html, body{
    width:100%;
    height:100%;
    margin:0;
    padding:0;
    overflow:hidden;
  }
  body{
    background:#02030a;
    font-family:system-ui,sans-serif;
    color:#fff;
  }

  /* 2. App full màn hình */
  .app{
    width:100vw;
    height:100vh;      /* fallback */
    height:100dvh;     /* dynamic viewport */
    position:fixed;
    inset:0;
    border-radius:0;   /* bỏ bo góc */
    border:none;       /* bỏ viền */
    box-shadow:none;   /* bỏ bóng */
    display:flex;
    flex-direction:column;
    overflow:hidden;
    background:#0f172a;
  }

  /* 3. Header né tai thỏ */
  .header{
    padding:14px 18px;
    padding-top:calc(14px + env(safe-area-inset-top, 0px));
    background:#1e293b;
    display:flex;
    justify-content:space-between;
    align-items:center;
  }

  /* 4. Nội dung giãn giữa */
  .body{
    flex:1;
    padding:16px;
    overflow-y:auto;
  }

  /* 5. Input né thanh điều hướng */
  .input{
    padding:12px 16px;
    padding-bottom:calc(16px + env(safe-area-inset-bottom, 0px));
    background:#1e293b;
    display:flex;
    gap:10px;
  }
  .input input{
    flex:1;
    padding:10px 14px;
    border-radius:20px;
    border:none;
    outline:none;
  }
  .input button{
    padding:10px 16px;
    border-radius:20px;
    border:none;
    background:#4F46E5;
    color:#fff;
    cursor:pointer;
  }
</style>
</head>
<body>

  <div class="app">
    <header class="header">
      <span>💬 MiniChat</span>
      <span>● 2 online</span>
    </header>

    <div class="body">
      <p>Nội dung chat...</p>
    </div>

    <div class="input">
      <input type="text" placeholder="Nhập tin nhắn..." />
      <button>Gửi</button>
    </div>
  </div>

</body>
</html>
```

Giải thích ngắn:

· <meta viewport-fit=cover> — cho phép nội dung tràn vào vùng tai thỏ iOS.
· html, body { overflow:hidden; padding:0 } — xóa scrollbar và mép trắng.
· .app { 100vw × 100dvh; position:fixed; inset:0 } — phủ full màn hình, không phụ thuộc body.
· border-radius:0; border:none; box-shadow:none — bỏ trang trí cũ.
· env(safe-area-inset-top/bottom) — đẩy header/input vào trong tránh bị che.

Lưu ý:

· Demo trên là bản rút gọn — không có Aurora Card, không Firebase, không Nature Scene.
· env() chỉ hoạt động khi có viewport-fit=cover trong meta viewport.
· Trên desktop, app sẽ chiếm hết cửa sổ — muốn giới hạn lại cần thêm @media (min-width: 768px).
