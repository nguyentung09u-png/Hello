khung card chat và nút nhập tin nhắn và nút gửi và màu text nhắn
----


Tổng quan cách làm (ngắn)

Theo cách tôi hiểu, khung chat cần 4 phần:

1. Khung ngoài — div bo góc 24px + backdrop-filter: blur() + flex-direction: column để xếp dọc header / chat box / input.
2. Vùng tin nhắn — div có overflow-y: auto, flex: 1, display: flex; flex-direction: column để các bong bóng xếp dọc và cuộn được.
3. Bong bóng — div bo góc 18px; dùng align-self: flex-start (người khác, nền xám nhạt) hoặc flex-end (mình, nền indigo).
4. Ô nhập + nút gửi — input bo tròn 30px, button tròn 48px chứa SVG.

Lưu ý: tôi không chắc backdrop-filter hiển thị giống nhau trên mọi trình duyệt — theo tôi biết Safari cần prefix -webkit-.

---

Code chung chung (minimal demo)

```html
<!DOCTYPE html>
<html>
<head>
<meta charset="UTF-8" />
<style>
  body{
    margin:0; height:100vh;
    display:grid; place-items:center;
    background:#02030a;
    font-family:system-ui,sans-serif;
  }

  /* 1. khung chat */
  .app-container{
    width:100%; max-width:420px; height:85vh;
    border-radius:24px;
    background:rgba(255,255,255,.85);
    backdrop-filter:blur(20px);
    -webkit-backdrop-filter:blur(20px);
    box-shadow:0 25px 50px -12px rgba(0,0,0,.25);
    display:flex; flex-direction:column;
    overflow:hidden;
  }

  /* 2. vùng tin nhắn */
  .chat-box{
    flex:1;
    padding:20px;
    overflow-y:auto;
    display:flex; flex-direction:column;
    gap:12px;
  }

  /* 3. bong bóng */
  .message{
    max-width:80%;
    padding:12px 16px;
    border-radius:18px;
    font-size:.95rem;
    line-height:1.4;
    word-wrap:break-word;
  }
  .message.mine{
    align-self:flex-end;
    background:#4F46E5;
    color:#fff;
    border-bottom-right-radius:4px;
  }
  .message.theirs{
    align-self:flex-start;
    background:#F3F4F6;
    color:#1F2937;
    border-bottom-left-radius:4px;
  }

  /* 4. ô nhập + nút gửi */
  .input-area{
    padding:16px 20px;
    display:flex; gap:12px; align-items:center;
    border-top:1px solid rgba(0,0,0,.05);
  }
  .input-area input{
    flex:1;
    padding:14px 20px;
    border-radius:30px;
    border:1px solid rgba(0,0,0,.1);
    background:rgba(255,255,255,.9);
    outline:none;
    transition:all .2s ease;
  }
  .input-area input:focus{
    border-color:#4F46E5;
    box-shadow:0 0 0 3px rgba(79,70,229,.1);
    background:#fff;
  }
  .input-area button{
    width:48px; height:48px;
    border-radius:50%;
    border:none;
    background:#4F46E5;
    color:#fff;
    cursor:pointer;
    box-shadow:0 4px 10px rgba(79,70,229,.3);
    transition:all .2s ease;
    display:flex; justify-content:center; align-items:center;
  }
  .input-area button:hover{
    background:#4338CA;
    transform:scale(1.05);
  }
  .input-area button svg{
    width:20px; height:20px;
    fill:currentColor;
    margin-left:-2px;
  }
</style>
</head>
<body>

  <div class="app-container">
    <div class="chat-box" id="chat-box">
      <div class="message theirs">Chào bạn 👋</div>
      <div class="message mine">Hi, mình mới vào</div>
    </div>

    <form class="input-area" id="chat-form">
      <input type="text" placeholder="Nhập tin nhắn..." autocomplete="off">
      <button type="submit">
        <svg viewBox="0 0 24 24"><path d="M2.01 21L23 12 2.01 3 2 10l15 2-15 2z"/></svg>
      </button>
    </form>
  </div>

<script>
  const box  = document.getElementById('chat-box');
  const form = document.getElementById('chat-form');
  const inp  = form.querySelector('input');

  form.addEventListener('submit', e => {
    e.preventDefault();
    const text = inp.value.trim();
    if (!text) return;

    // thêm bong bóng "mình"
    const mine = document.createElement('div');
    mine.className = 'message mine';
    mine.textContent = text;
    box.appendChild(mine);

    inp.value = '';
    box.scrollTop = box.scrollHeight;
  });
</script>
</body>
</html>
```

Giải thích ngắn:

· .app-container — khung ngoài bo 24px + blur, dùng flex-direction: column.
· .chat-box — flex: 1 để giãn hết, overflow-y: auto để cuộn.
· .message.mine / .message.theirs — khác nhau ở align-self + màu nền.
· JS demo chỉ thêm bong bóng "mình" khi submit; chưa có server nên không có tin từ người khác.

Lưu ý: code trên không có Firebase — chỉ mô phỏng giao diện + hành vi gửi. Muốn chat thật cần thêm SDK Firebase và hàm push()/onValue().
