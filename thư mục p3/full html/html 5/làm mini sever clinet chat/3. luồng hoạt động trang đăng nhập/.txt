Tổng quan cách làm (ngắn)

Theo cách tôi hiểu, để dựng 2 luồng đó cần 4 khối phối hợp:

1. localStorage — lưu/đọc userId và userName.
2. Đoạn if lúc load — kiểm tra 2 key này để rẽ nhánh: có userName → vào chat, chưa có → hiện form.
3. Cặp hàm showLogin() / handleLogin() — điều khiển ẩn/hiện UI và lưu tên khi bấm nút.
4. initializeChat() — hiện khung chat, kết nối Firebase, gửi tin "đã tham gia".

Lưu ý: tôi không chắc bạn muốn code "chung chung" theo hướng nào — dưới đây là bản demo tối thiểu, không có Firebase thật, chỉ mô phỏng luồng.

---

Code chung chung (minimal demo)

```html
<!DOCTYPE html>
<html>
<head>
<meta charset="UTF-8" />
<style>
  body{ margin:0; height:100vh; display:grid; place-items:center;
        background:#02030a; color:#fff; font-family:system-ui; }

  .hidden{ display:none !important; }

  #login-stage{ padding:24px; border-radius:16px; background:#1e1b4b; }
  #login-stage input{ padding:10px; border-radius:8px; border:none; }
  #login-stage button{ padding:10px 16px; border-radius:8px; border:none;
                       background:#7c3aed; color:#fff; cursor:pointer; }

  #chat-app{ padding:24px; border-radius:16px; background:#111827; }
</style>
</head>
<body>

  <!-- Màn hình đăng nhập -->
  <div id="login-stage">
    <h2>MiniChat</h2>
    <input type="text" id="username-input" placeholder="Tên của bạn...">
    <button id="join-btn">Bắt đầu Chat</button>
  </div>

  <!-- Khung chat -->
  <div id="chat-app" class="hidden">
    <h2>💬 MiniChat</h2>
    <p id="welcome"></p>
    <p>Khung chat ở đây...</p>
  </div>

<script>
  // ---------- 1. localStorage ----------
  let userId   = localStorage.getItem('minichat_userId');
  let userName = localStorage.getItem('minichat_userName');

  // Sinh userId nếu chưa có (độc lập với userName)
  if (!userId) {
    userId = 'user_' + Math.random().toString(36).substring(2, 9);
    localStorage.setItem('minichat_userId', userId);
  }

  // ---------- DOM ----------
  const loginStage = document.getElementById('login-stage');
  const chatApp    = document.getElementById('chat-app');
  const input      = document.getElementById('username-input');
  const joinBtn    = document.getElementById('join-btn');
  const welcome    = document.getElementById('welcome');

  // ---------- 3. showLogin / handleLogin ----------
  function showLogin() {
    loginStage.classList.remove('hidden');
    chatApp.classList.add('hidden');
    input.value = userName || '';
    input.focus();
  }

  function handleLogin() {
    const name = input.value.trim();
    if (!name) return;                              // validate rỗng
    userName = name;
    localStorage.setItem('minichat_userName', userName); // lưu tên
    loginStage.classList.add('hidden');
    initializeChat();                               // vào chat
  }

  joinBtn.addEventListener('click', handleLogin);
  input.addEventListener('keypress', e => {
    if (e.key === 'Enter') handleLogin();
  });

  // ---------- 4. initializeChat ----------
  function initializeChat() {
    chatApp.classList.remove('hidden');
    welcome.textContent = `Xin chào ${userName} (ID: ${userId})`;

    // TODO: kết nối Firebase + push tin "X đã tham gia"
    // Ví dụ (pseudo):
    // push(ref(db, 'messages'), {
    //   userId: 'system',
    //   text: `${userName} đã tham gia phòng chat.`,
    //   isSystem: true
    // });
  }

  // ---------- 2. Rẽ nhánh lúc load ----------
  if (userName) {
    // Luồng 2: có sẵn tên → vào thẳng
    loginStage.classList.add('hidden');
    initializeChat();
  } else {
    // Luồng 1: chưa có → hiện form
    showLogin();
  }
</script>
</body>
</html>
```

Giải thích ngắn:

· if (!userId) {...} — sinh ID ngay khi load, không chờ nhập tên.
· if (userName) {...} else {...} — rẽ nhánh luồng 1 / luồng 2.
· handleLogin() — validate rỗng → lưu tên → ẩn form → gọi initializeChat().
· initializeChat() — hiện khung chat, hiển thị tên + ID; chỗ Firebase để TODO.

Lưu ý: code trên không có Firebase thật — chỉ mô phỏng luồng UI + localStorage. Muốn chat thật cần thêm SDK Firebase và hàm push().
