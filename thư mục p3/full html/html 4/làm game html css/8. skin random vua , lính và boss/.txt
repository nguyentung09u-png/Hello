🎨 SKIN RANDOM MỖI MÀN — CÁCH LÀM (TỔNG QUAN)

🎯 Nguyên tắc cốt lõi

Skin random = 1 bảng màu cố định + 1 PRNG có seed + 4 điểm đọc màu:

```
BƯỚC 1: BẢNG MÀU   viết object SKINS chứa nhiều bộ màu
BƯỚC 2: PRNG       dùng mulberry32(seed) thay Math.random()
BƯỚC 3: HÀM CHỌN   viết pickSkin(level) trả về 4 bộ
BƯỚC 4: GÁN        game.skin = pickSkin(level) khi bắt đầu màn
BƯỚC 5: ĐỌC MÀU    4 hàm draw đọc từ game.skin thay vì màu cứng
```

Điểm mấu chốt: PRNG có seed = level → cùng level luôn ra cùng bộ màu. Không random mỗi frame.

---

🔍 Năm bước chi tiết

Bước 1 — Viết bảng màu SKINS

Mỗi loại quân có nhiều bộ màu, mỗi bộ là 1 object chứa các mã màu cụ thể:

```js
const SKINS = {
  guard: [   // 7 bộ
    { armor: ['#c94b4b','#8a2c2c'], helmet: '#9aa3b0', crest: '#d8443c' },
    { armor: ['#3a5ac9','#1f3a8a'], helmet: '#c9c9c9', crest: '#4f9ff7' },
    // ...
  ],
  archer: [  // 6 bộ
    { tunic: ['#3d7a3d','#1e4a1e'], hood: '#1e4a1e' },
    // ...
  ],
  king: [    // 6 bộ
    { robe: ['#f0d074','#d8ab3c','#a3791d'], cape: '#6d1b36', crown: '#ffd447' },
    // ...
  ],
  boss: [    // 6 bộ
    { body: ['#4a2f5f','#241536'], eye: '#ff4d4d', aura: 'rgba(255,60,60,0.55)' },
    // ...
  ]
};
```

Điểm mấu chốt: mỗi loại có số trường khác nhau tuỳ chi tiết cần đổi màu.

Bước 2 — Viết PRNG mulberry32

```js
function mulberry32(a) {
  return function () {
    a |= 0; a = a + 0x6D2B79F5 | 0;
    let t = Math.imul(a ^ a >>> 15, 1 | a);
    t = t + Math.imul(t ^ t >>> 7, 61 | t) ^ t;
    return ((t ^ t >>> 14) >>> 0) / 4294967296;
  };
}
```

→ Cùng seed → cùng dãy số → dùng cho tính deterministic.

Bước 3 — Viết hàm pickSkin(level)

```js
function pickSkin(level) {
  const rng = mulberry32(level * 7919 + 42);   // ← seed từ level
  return {
    guard:  SKINS.guard [Math.floor(rng() * SKINS.guard.length)],
    archer: SKINS.archer[Math.floor(rng() * SKINS.archer.length)],
    king:   SKINS.king  [Math.floor(rng() * SKINS.king.length)],
    boss:   SKINS.boss  [Math.floor(rng() * SKINS.boss.length)]
  };
}
```

Pattern Math.floor(rng() * length):

· rng() trả về float 0 → 1
· Nhân với length → float 0 → length
· Math.floor → int 0 → length-1 → index hợp lệ

Bước 4 — Gán skin khi bắt đầu màn

Trong startLevel():

```js
function startLevel() {
  game.skin = pickSkin(game.level);   // ← gán 1 lần
  game.waveActive = true;
  // ...
}
```

Trong startGame():

```js
game.skin = pickSkin(1);              // ← màn 1 ban đầu
```

→ Chỉ gán 1 lần — không đổi giữa các frame.

Bước 5 — Sửa 4 hàm draw đọc màu

Trước:

```js
function drawGuard(s, t) {
  bg.addColorStop(0, '#c94b4b');        // ← màu cứng
  bg.addColorStop(1, '#8a2c2c');
  ctx.fillStyle = '#9aa3b0';            // ← màu cứng
  // ...
}
```

Sau:

```js
function drawGuard(s, t) {
  const sk = game.skin?.guard || SKINS.guard[0];   // ← đọc skin
  bg.addColorStop(0, sk.armor[0]);                  // ← màu từ skin
  bg.addColorStop(1, sk.armor[1]);
  ctx.fillStyle = sk.helmet;                        // ← màu từ skin
  // ...
}
```

Fallback || SKINS.guard[0]:

· Nếu game.skin là null/undefined → dùng bộ #0
· Đảm bảo không lỗi khi chưa gán skin

  ctx.fill();
}

🎨 Tham số có thể chỉnh

Tham số Mặc định Đổi để làm gì
Số bộ trong SKINS 7/6/6/6 Thêm/bớt màu
Seed level * 7919 + 42 Công thức Đổi cách chọn skin
Số lần rng() 4 1 cho mỗi loại
**Fallback `  SKINS.x[0]`**

---

⚠️ Điều tôi không chắc

· Số bộ màu cụ thể (7, 6, 6, 6) — tôi chọn theo trực giác, không có dữ liệu tối ưu.
· Công thức seed level * 7919 + 42 — tôi chọn; 7919 là số nguyên tố, 42 là số bất kỳ. Không có cơ sở toán học khẳng định đây là tối ưu.
· PRNG mulberry32 — tôi cho là phân bố đều, nhưng không có dữ liệu kiểm định thống kê.
· Việc rng() gọi 4 lần liên tiếp có tương quan gì giữa 4 lần không — tôi không chắc, thường thì không.
· Bảng màu chỉ đổi giáp/áo/vương miện/thân boss — da, mắt, râu, ngọc, giày vẫn cố định. Nếu muốn đổi luôn thì cần thêm trường vào SKINS.
· Fallback || SKINS.x[0] chỉ chạy khi game.skin là null/undefined — trong thực tế hiếm khi xảy ra vì startLevel() luôn gán trước.
· Có nên lưu skin vào localStorage để chơi lại giữ nguyên skin không — tôi không làm, vì skin tính từ level là deterministic rồi.

🎯 TÓM 1 CÂU

Cách làm: viết bảng màu SKINS (object 4 mảng — 7 guard / 6 archer / 6 king / 6 boss, mỗi phần tử là 1 object chứa các mã màu cụ thể) + viết PRNG mulberry32(seed) (cùng seed → cùng dãy số) + viết hàm pickSkin(level) dùng seed level * 7919 + 42 gọi rng() 4 lần để chọn index Math.floor(rng() * length) cho từng loại + gán game.skin = pickSkin(level) 1 lần trong startLevel() + sửa 4 hàm draw đọc game.skin?.{loại} || SKINS.{loại}[0] thay vì màu cứng.
