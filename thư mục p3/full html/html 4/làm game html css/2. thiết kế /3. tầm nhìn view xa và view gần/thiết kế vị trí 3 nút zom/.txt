Tổng quan cách làm (3 lớp)

```
LỚP 1 — HTML   1 div cha + 3 button (data-zoom)
LỚP 2 — CSS    position absolute + flex column + căn giữa dọc
LỚP 3 — JS     state cam + 3 hàm + gắn sự kiện click
```

Nguyên tắc chung: HTML dựng khung, CSS định vị và tạo hình, JS xử lý hành động và đồng bộ trạng thái active.

Code chung chung

1. HTML

```html
<div id="zoomBar">
  <button data-zoom="in">−</button>
  <button data-zoom="reset" class="active">=</button>
  <button data-zoom="out">+</button>
</div>
```

3. JS — State + hàm

```js
const cam = {
  zoom: 1,
  targetZoom: 1,
  smooth: 0.22
};
const MIN_ZOOM = 0.15;
const MAX_ZOOM = 2.5;
const ZOOM_STEP = 1.20;

const clamp = (v,a,b) => v < a ? a : v > b ? b : v;

function zoomBy(factor){
  const oldZ = cam.targetZoom;
  const newZ = clamp(oldZ * factor, MIN_ZOOM, MAX_ZOOM);
  if (newZ === oldZ) return;
  cam.targetZoom = newZ;
  refreshZoomButtons();
}

function resetZoom(){
  cam.targetZoom = 1;
  refreshZoomButtons();
}

function refreshZoomButtons(){
  const atReset = Math.abs(cam.targetZoom - 1) < 0.001;
  document.querySelector('[data-zoom="reset"]')
    .classList.toggle('active', atReset);
}
```

4. JS — Gắn sự kiện

```js
document.querySelectorAll('#zoomBar button').forEach(btn => {
  btn.addEventListener('click', e => {
    e.stopPropagation();               // không lan ra canvas
    const k = btn.dataset.zoom;
    if (k === 'in')    zoomBy(1/ZOOM_STEP);   // − gần hơn
    if (k === 'out')   zoomBy(ZOOM_STEP);     // + xa hơn
    if (k === 'reset') resetZoom();
  });
  btn.addEventListener('pointerdown', e => e.stopPropagation());
});
```

5. JS — Lerp camera mỗi frame

```js
function updateCamera(dt){
  const k = 1 - Math.pow(1 - cam.smooth, dt * 60);
  cam.zoom += (cam.targetZoom - cam.zoom) * k;
}
```

6. JS — Áp camera khi vẽ

```js
function render(){
  ctx.save();
  ctx.scale(cam.zoom, cam.zoom);
  // ... vẽ world ...
  ctx.restore();
}
```

Điều tôi không chắc

· 46px, right:14px, gap:8px — tôi chọn theo trực giác; khuyến nghị vùng chạm ≥ 44px, nên 46 ổn nhưng tôi không chắc là tối ưu.
· top: 50% + translateY(-50%) là cách căn giữa dọc phổ biến; tôi tin đúng, nhưng có cách khác (inset-block:0; margin-block:auto) tương đương.
· ZOOM_STEP = 1.20 và MIN/MAX_ZOOM = 0.15/2.5 — tôi chọn theo cảm giác; không có dữ liệu tối ưu.
· smooth = 0.22 cho lerp — tôi chọn; đổi cao → mượt hơn nhưng chậm, đổi thấp → phản hồi nhanh nhưng giật.
· e.stopPropagation() ở cả click và pointerdown — tôi tin đủ để nút không kích hoạt canvas, nhưng trên một số trình duyệt mobile có thể vẫn lan; tôi không test được mọi trình duyệt.
· Thứ tự trên xuống − → = → + — tôi giữ theo HTML hiện có; tôi không chắc bạn muốn thứ tự này.
