Tổng quan cách làm (3 lớp)

Lớp 1 — HTML: 1 <div> chứa 3 <button>, mỗi nút có data-zoom để phân biệt.
Lớp 2 — CSS: tạo hình tròn vàng, hiệu ứng bấm, class .active cho nút =.
Lớp 3 — JS: gắn click → gọi hàm zoom → đổi cam.targetZoom → lerp mượt.

---

```html
<div id="zoomBar">
  <button data-zoom="in">−</button>

</div>
```

3. JS — State camera

```js
const cam = {
  zoom:1, targetZoom:1,
  x:0, y:0, targetX:0, targetY:0,
  smooth:0.20
};
const ZOOM_STEP = 1.20;
const MIN_ZOOM  = 0.18;
const MAX_ZOOM  = 3.0;

const clamp = (v,a,b) => v<a?a : v>b?b : v;
```

4. JS — Zoom giữ điểm neo (mặc định tâm)

```js
function zoomBy(factor, anchorX, anchorY){
  if (anchorX === undefined) anchorX = W/2;
  if (anchorY === undefined) anchorY = H/2;

  const oldZ = cam.targetZoom;
  const newZ = clamp(oldZ * factor, MIN_ZOOM, MAX_ZOOM);
  if (newZ === oldZ) return;

  const wx = (anchorX - cam.targetX) / oldZ;
  const wy = (anchorY - cam.targetY) / oldZ;

  cam.targetZoom = newZ;
  cam.targetX = anchorX - wx * newZ;
  cam.targetY = anchorY - wy * newZ;

  clampCamera();          // tuỳ dự án có/không
  refreshZoomButtons();
}

function resetZoom(){
  cam.targetZoom = 1;
  cam.targetX = 0;
  cam.targetY = 0;
  refreshZoomButtons();
}
```

5. JS — Bật/tắt class active cho nút =

```js
function refreshZoomButtons(){
  const atReset = Math.abs(cam.targetZoom - 1) < 0.001;
  document.querySelector('[data-zoom="reset"]')
    .classList.toggle('active', atReset);
}
```

6. JS — Lerp camera mỗi frame

```js
function updateCamera(dt){
  const k = 1 - Math.pow(1 - cam.smooth, dt * 60);
  cam.zoom += (cam.targetZoom - cam.zoom) * k;
  cam.x    += (cam.targetX    - cam.x)    * k;
  cam.y    += (cam.targetY    - cam.y)    * k;
  // clampCamera(); // nếu có biên world
}
```

7. JS — Gắn sự kiện click

```js
document.querySelectorAll('#zoomBar button').forEach(btn => {
  btn.addEventListener('click', e => {
    e.stopPropagation();
    const k = btn.dataset.zoom;
    if (k === 'in')    zoomBy(1 / ZOOM_STEP);  // − gần hơn
    if (k === 'out')   zoomBy(ZOOM_STEP);      // + xa hơn
    if (k === 'reset') resetZoom();
  });
  btn.addEventListener('pointerdown', e => e.stopPropagation());
});
```

8. JS — Áp camera khi vẽ

```js
function render(t){
  ctx.save();
  ctx.translate(cam.x, cam.y);
  ctx.scale(cam.zoom, cam.zoom);

  // ... vẽ world ...

  ctx.restore();
}
```

9. Vòng lặp chính

```js
function loop(ts){
  const dt = Math.min((ts - last)/1000, 0.05);
  last = ts;
  updateCamera(dt);
  render(ts/1000);
  requestAnimationFrame(loop);
}
requestAnimationFrame(loop);
```

---

Điều tôi không chắc

· ZOOM_STEP = 1.20, MIN_ZOOM = 0.18, MAX_ZOOM = 3.0 — tôi chọn theo trực giác, không có dữ liệu tối ưu.
· Điểm neo mặc định W/2, H/2 — hợp lý nhưng không bắt buộc; có thể đổi sang toạ độ con trỏ.
· clampCamera() — chỉ cần khi world có biên. Nếu world vô hạn thực sự thì bỏ được. Tôi không chắc bạn muốn giữ hay bỏ.
· e.stopPropagation() ở cả click và pointerdown — tôi tin là đủ để nút không kích hoạt canvas, nhưng trên một số trình duyệt mobile có thể vẫn có sự kiện lan, tôi không test được.
· class="active" — chỉ làm sáng nút =. Tôi không chắc bạn muốn làm mờ nút +/− khi đã chạm MIN_ZOOM/MAX_ZOOM.
