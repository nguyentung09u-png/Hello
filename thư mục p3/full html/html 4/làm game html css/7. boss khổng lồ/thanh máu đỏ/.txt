🔴 2 LOẠI THANH MÁU BOSS — CÁCH LÀM (TỔNG QUAN)

🎯 Nguyên tắc cốt lõi

Cả 2 thanh máu đều làm theo cùng 1 công thức, chỉ khác công cụ vẽ:

```
BƯỚC 1: NỀN     khung đen làm viền
BƯỚC 2: RUỘT    thanh gradient đỏ co giãn theo %HP
BƯỚC 3: CẬP NHẬT mỗi frame theo máu hiện tại
```

Khác biệt:

 Loại A (top) Loại B (trên đầu)
Công cụ HTML/CSS Canvas 2D
Co giãn style.width = % w * pct
Vẽ ở đâu updateHUD() drawEnemy()
Dữ liệu Tổng HP tất cả boss HP của boss đó

---

🔍 Cách làm — LOẠI A (Boss HP Bar đầu màn hình)

Bước 1 — HTML khung

```html
<div id="bossBar">
  <div class="name">👹 QUÁI KHỔNG LỒ</div>
  <div class="bg"><div class="fill" id="bossHpFill"></div></div>
  <div class="count" id="bossHpCount">1 / 1</div>
</div>
```

→ 3 lớp: tiêu đề + khung + ruột.

Bước 2 — CSS vẽ thanh đỏ

```css
#bossBar{
  position:absolute; top:100px; left:50%;

  width:min(72vw,540px);
  display:none;                 /* ← ẩn mặc định */

#bossBar .bg{

  border:1.5px solid rgba(255,60,60,.55);
  box-shadow:0 0 20px rgba(255,40,40,.5);

}
#bossBar .fill{
  height:100%;width:100%;
  background:linear-gradient(90deg,#4a0808,#a01818 40%,#ff3030 75%,#ff7070);

  transition:width .25s ease-out;   /* ← mượt khi mất máu */
}
```

→ Gradient 4 điểm + box-shadow đỏ = "máu boss".

Bước 3 — JS cập nhật

```js
function updateHUD() {
  if (game.phase === 'boss' && game.waveActive) {
    bossBarEl.classList.add('show');

    // Gộp HP tất cả boss còn sống
    const bosses = enemies.filter(e => e.giant && e.hp > 0);
    const curHp = bosses.reduce((s, e) => s + e.hp, 0);
    const maxHp = bosses.reduce((s, e) => s + e.maxHp, 0);

    bossFillEl.style.width = (curHp / maxHp) * 100 + '%';
    bossCountEl.textContent = bosses.length + ' / ' + bossCount(game.level) + ' còn lại';
  } else {
    bossBarEl.classList.remove('show');   // ← ẩn khi không phải boss
  }
}
```

→ Mỗi frame: đếm boss còn sống → tính tổng HP → gán width.

🔍 Cách làm — LOẠI B (Overhead HP bar trên đầu boss)

Bước 1 — Hàm vẽ 2 lớp

```js
function drawBar(x, y, w, h, pct, c1, c2) {
  pct = clamp(pct, 0, 1);

  // LỚP 1: nền đen làm viền (to hơn 1.2px mỗi phía)
  ctx.fillStyle = 'rgba(0,0,0,0.62)';
  rr(ctx, x-w/2-1.2, y-1.2, w+2.4, h+2.4, (h+2.4)/2);
  ctx.fill();

  if (pct <= 0) return;

  // LỚP 2: ruột máu gradient ngang
  const g = ctx.createLinearGradient(x-w/2, 0, x+w/2, 0);
  g.addColorStop(0, c1);
  g.addColorStop(1, c2);
  ctx.fillStyle = g;
  rr(ctx, x-w/2, y, w*pct, h, h/2);   // ← co giãn theo pct
  ctx.fill();
}
```

Bước 2 — Gọi trong drawEnemy()

```js
if (e.hp < e.maxHp && cam.zoom >= 0.7) {

}
```

→ Mỗi boss có 1 thanh riêng, dính trên đầu.

💻 CODE KHUNG (chung chung)

```js
// ============================
// LOẠI B — HÀM VẼ CHUNG (canvas)
// ============================
function rr(c, x, y, w, h, r) {
  r = Math.min(r, w/2, h/2);
  c.beginPath();
  c.moveTo(x+r, y);
  c.arcTo(x+w, y, x+w, y+h, r);
  c.arcTo(x+w, y+h, x, y+h, r);
  c.arcTo(x, y+h, x, y, r);
  c.arcTo(x, y, x+w, y, r);
  c.closePath();
}

function drawBar(x, y, w, h, pct, c1, c2) {
  pct = Math.max(0, Math.min(1, pct));

  // Nền đen làm viền
  ctx.fillStyle = 'rgba(0,0,0,0.62)';
  rr(ctx, x-w/2-1.2, y-1.2, w+2.4, h+2.4, (h+2.4)/2);
  ctx.fill();

  if (pct <= 0) return;

  // Ruột máu gradient
  const g = ctx.createLinearGradient(x-w/2, 0, x+w/2, 0);
  g.addColorStop(0, c1);
  g.addColorStop(1, c2);
  ctx.fillStyle = g;
  rr(ctx, x-w/2, y, w*pct, h, h/2);
  ctx.fill();
}

// ============================
// LOẠI B — GỌI TRONG drawEnemy()
// ============================
function drawEnemy(e, t) {
  // ... vẽ thân boss ...
  drawBossBody(e, t);

  // HP bar chỉ hiện khi mất máu và zoom đủ gần
  if (e.hp < e.maxHp && cam.zoom >= 0.7) {
    if (e.giant) {
      drawBar(e.x, e.y - 130, 80, 7, e.hp/e.maxHp,
              '#6a1a1a', game.skin?.boss?.eye || '#ff3030');
    } else {
      const sc = scaleAt(e.y);
      drawBar(e.x, e.y - 50*sc, 26*sc*0.75, 3.2, e.hp/e.maxHp,
              '#a83232', '#ff6b5c');
    }
  }
}

// ============================
// LOẠI A — DOM + CSS
// ============================
// HTML: <div id="bossBar">...</div> (đặt 1 lần trong body)

const bossBarEl  = document.getElementById('bossBar');
const bossFillEl = document.getElementById('bossHpFill');
const bossCountEl = document.getElementById('bossHpCount');

function updateBossBar() {
  if (game.phase === 'boss' && game.waveActive) {
    bossBarEl.classList.add('show');

    const bosses = enemies.filter(e => e.giant && e.hp > 0);
    const curHp = bosses.reduce((s, e) => s + e.hp, 0);
    const maxHp = bosses.reduce((s, e) => s + e.maxHp, 0);
    const pct = maxHp > 0 ? (curHp / maxHp) * 100 : 0;

    bossFillEl.style.width = pct + '%';
    bossCountEl.textContent = bosses.length + ' / ' + bossCount(game.level) + ' còn lại';
  } else {
    bossBarEl.classList.remove('show');
  }
}

// Gọi trong vòng lặp
function updateHUD() {
  updateBossBar();
  // ... phần còn lại của HUD
}

// ============================
// VÒNG LẶP
// ============================
function loop(now) {
  const dt = Math.min((now - last) / 1000, 0.05);
  last = now;

  update(dt);        // logic game
  render(now);       // vẽ canvas → drawEnemy() → drawBar()
  updateHUD();       // cập nhật DOM → updateBossBar()

  requestAnimationFrame(loop);
}
```

🎨 Tham số có thể chỉnh

Tham số Mặc định Đổi để làm gì
Vị trí top 100px HP bar cao/thấp
Rộng A / B 72vw / 80px Thanh dài/ngắn
Cao A / B 16px / 7px Thanh dày/mỏng
Màu gradient #4a0808 → #ff7070 Đỏ sậm/nhạt khác
e.y - 130 130px Vị trí trên đầu boss
cam.zoom >= 0.7 0.7 Ngưỡng ẩn/hiện thanh B

---

⚠️ Điều tôi không chắc

· Con số cụ thể (rộng 80, cao 7, y - 130, gradient 4 điểm) — tôi chọn theo trực giác, không có dữ liệu tối ưu.
· Loại A gộp tất cả boss — khi có 4 boss cùng lúc, thanh = tổng HP. Nếu muốn mỗi boss 1 thanh riêng thì dùng loại B, hoặc dùng cả 2.
· transition: width .25s trên loại A — có thể gây lag nhẹ khi HP thay đổi rất nhanh (mỗi frame), nhưng thực tế không đáng kể vì CSS transition thường mượt.
· skin.boss.eye làm màu phải của thanh B — có thể lệch tông nếu skin boss có màu mắt khác đỏ (cyan, vàng). Tôi không chắc điều này thị giác tốt không.
· Điều kiện e.hp < e.maxHp ẩn thanh khi boss đầy máu — có thể không như ý nếu bạn muốn luôn hiện thanh (kể cả khi đầy).
· Dùng ctx.save()/restore() bao quanh drawBar — không cần trong code này vì chỉ đổi fillStyle, nhưng nếu mở rộng có thể cần.
· Việc vẽ HP bar trong drawEnemy vs tách thành drawBossBar riêng — cả hai đều được, nhưng tách ra dễ bảo trì hơn.
