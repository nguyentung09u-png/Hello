Tổng quan cách làm "tự xoay 4 góc khi thả tay 1 giây"

Các bước chính

1. Ghi mốc thời gian khi chuột di chuyển

· Mỗi lần pointermove → cập nhật lastMove = performance.now()
· Đồng thời reset idleStart = 0 để pha idle được tính lại từ đầu

2. Kiểm tra đã rảnh đủ lâu chưa

· Trong vòng lặp: if (now - lastMove > 1000) → đã rảnh ≥ 1 giây

3. Chốt mốc bắt đầu idle

· Lần đầu vào idle: idleStart = now
· Tính t = (now - idleStart) / 1000

4. Tính góc mục tiêu theo quỹ đạo tròn

· try_ =  A * Math.cos(t * speed) — trục Y
· trx  = -A * Math.sin(t * speed) — trục X
· Cặp (cos, sin) ngược pha → điểm chạy vòng quanh tâm

5. Làm mượt bằng lerp

· ry += (try_ - ry) * k
· rx += (trx  - rx) * k

6. Áp vào CSS

· card.style.setProperty('--rx', rx + 'deg')
· card.style.setProperty('--ry', ry + 'deg')

7. Lặp bằng requestAnimationFrame

---

Code chung chung

```html
<!DOCTYPE html>
<html>
<head>
<meta charset="UTF-8" />
<style>
  body{
    margin:0; height:100vh;
    display:grid; place-items:center;
    background:#0a0c15;
    font-family:system-ui,sans-serif;
  }

  /* perspective tạo chiều sâu 3D */
  .stage{ perspective: 1000px; }

  .card{
    width:240px; height:320px;
    border-radius:18px;
    background:linear-gradient(160deg,#1e1b4b,#0a0c15);
    color:#fff;
    display:grid; place-items:center;
    font-weight:700;
    transform-style: preserve-3d;
    transform: rotateX(var(--rx,0deg)) rotateY(var(--ry,0deg));
    transition: transform .1s linear;
    will-change: transform;
  }
</style>
</head>
<body>

  <div class="stage">
    <div class="card" id="card">Card</div>
  </div>

<script>
  const card = document.getElementById('card');

  let rx = 0, ry = 0;      // góc hiện tại (hiển thị)
  let trx = 0, try_ = 0;   // góc mục tiêu

  let lastMove = 0;        // mốc chuột di chuyển lần cuối
  let idleStart = 0;       // mốc bắt đầu rảnh

  // ===== chuột di chuyển → cập nhật mục tiêu =====
  window.addEventListener('pointermove', e => {
    const r = card.getBoundingClientRect();
    const cx = r.left + r.width / 2;
    const cy = r.top  + r.height / 2;

    const nx = Math.max(-1, Math.min(1, (e.clientX - cx) / (r.width  / 2)));
    const ny = Math.max(-1, Math.min(1, (e.clientY - cy) / (r.height / 2)));

    try_ =  nx * 15;   // trục Y
    trx  = -ny * 15;   // trục X

    lastMove = performance.now();
    idleStart = 0;     // reset pha idle
  }, { passive:true });

  // ===== vòng lặp render =====
  function loop(now){
    // nếu rảnh ≥ 1 giây → tự xoay quỹ đạo tròn
    if (now - lastMove > 1000){
      if (!idleStart) idleStart = now;         // chốt mốc bắt đầu
      const t = (now - idleStart) / 1000;      // giây kể từ khi rảnh

      const A = 15;        // biên độ nghiêng (độ)
      const speed = 0.9;   // tốc độ chạy vòng

      try_ =  A * Math.cos(t * speed);         // Y
      trx  = -A * Math.sin(t * speed);         // X
    }

    // lerp làm mượt
    ry += (try_ - ry) * 0.08;
    rx += (trx  - rx) * 0.08;

    card.style.setProperty('--rx', rx.toFixed(2) + 'deg');
    card.style.setProperty('--ry', ry.toFixed(2) + 'deg');

    requestAnimationFrame(loop);
  }
  requestAnimationFrame(loop);
</script>
</body>
</html>
```

---

Giải thích ngắn từng phần

Phần Vai trò
lastMove Biết chuột vừa mới di chuyển hay đã lâu không đụng
idleStart Chốt mốc để t đếm từ 0, tránh nhảy loạn
now - lastMove > 1000 Điều kiện "rảnh ≥ 1 giây"
cos / sin ngược pha Vẽ quỹ đạo tròn qua 4 hướng
Lerp * 0.08 Làm chuyển động mượt
requestAnimationFrame Vòng lặp render mỗi frame

Lưu ý (tôi không chắc): hệ số lerp 0.08 và tốc độ 0.9 là giá trị tham khảo, không phải tối ưu cho mọi trường hợp.

---

Tóm 1 câu

Ghi mốc lastMove khi chuột di chuyển → trong vòng requestAnimationFrame kiểm tra now - lastMove > 1000, nếu đúng thì chốt idleStart và tính góc mục tiêu bằng try_ = A·cos(t·speed), trx = −A·sin(t·speed) → lerp về --rx/--ry để card tự xoay vòng qua 4 hướng.
