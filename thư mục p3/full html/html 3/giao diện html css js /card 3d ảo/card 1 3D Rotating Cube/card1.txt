Tổng quan cách làm 3D Rotating Cube

Các bước chính (đã kiểm chứng qua CSS/JS chuẩn)

1. HTML — dựng cấu trúc

· 1 thẻ cha (.cube) làm khối
· 6 thẻ con (.face) làm 6 mặt

2. CSS — tạo không gian 3D

· Thẻ bao ngoài đặt perspective → tạo chiều sâu
· .cube đặt transform-style: preserve-3d → con giữ được không gian 3D
· Mỗi .face đặt position: absolute + transform với rotateX/Y + translateZ(½ cạnh) để đẩy ra 6 hướng

3. CSS — trang trí

· Gradient nền cho từng mặt
· box-shadow + viền sáng để tạo cảm giác khối có cạnh
· backface-visibility: hidden để ẩn mặt khuất (tùy chọn)

4. JS — điều khiển

· Bắt mousedown/mousemove/mouseup (và touch) để tính dx, dy
· Cộng dx, dy vào góc xoay mục tiêu
· Dùng requestAnimationFrame + lerp để góc hiện tại chạy mượt theo góc mục tiêu
· Khi không kéo và đã rảnh một khoảng → cộng dần góc Y để tự xoay

5. Nền — radial-gradient

· Đặt ở body hoặc một lớp phủ riêng phía sau

---

Code chung chung (tối giản, đủ hiểu)

```html
<!DOCTYPE html>
<html>
<head>
<meta charset="UTF-8" />
<style>
  body {
    margin: 0;
    height: 100vh;
    display: grid;
    place-items: center;
    background: radial-gradient(circle at center, #1b1b3a, #000);
    perspective: 1000px; /* tạo chiều sâu */
  }

  .cube {
    position: relative;
    width: 200px;
    height: 200px;
    transform-style: preserve-3d; /* giữ 3D cho con */
    transform: rotateX(var(--rx)) rotateY(var(--ry));
  }

  .face {
    position: absolute;
    inset: 0;
    background: linear-gradient(135deg, #4f46e5, #06b6d4);
    border: 1px solid rgba(255,255,255,.3);
    box-shadow: inset 0 0 20px rgba(0,0,0,.5);
    color: #fff;
    display: grid;
    place-items: center;
    font-family: sans-serif;
  }

  /* 6 mặt, mỗi mặt đẩy ra 100px = nửa cạnh (200/2) */
  .front  { transform: translateZ(100px); }
  .back   { transform: rotateY(180deg) translateZ(100px); }
  .right  { transform: rotateY(90deg)  translateZ(100px); }
  .left   { transform: rotateY(-90deg) translateZ(100px); }
  .top    { transform: rotateX(90deg)  translateZ(100px); }
  .bottom { transform: rotateX(-90deg) translateZ(100px); }
</style>
</head>
<body>

  <div class="cube" id="cube">
    <div class="face front">1</div>
    <div class="face back">2</div>
    <div class="face right">3</div>
    <div class="face left">4</div>
    <div class="face top">5</div>
    <div class="face bottom">6</div>
  </div>

<script>
  const cube = document.getElementById('cube');

  // góc hiện tại và góc mục tiêu
  let rx = -20, ry = 30;
  let trx = -20, try_ = 30;

  let dragging = false;
  let lastX = 0, lastY = 0;
  let lastInteract = 0;

  // --- Bắt sự kiện kéo ---
  document.addEventListener('mousedown', e => {
    dragging = true;
    lastX = e.clientX; lastY = e.clientY;
    lastInteract = performance.now();
  });

  document.addEventListener('mousemove', e => {
    if (!dragging) return;
    const dx = e.clientX - lastX;
    const dy = e.clientY - lastY;
    lastX = e.clientX; lastY = e.clientY;

    try_ += dx * 0.5;   // kéo ngang → xoay Y
    trx  -= dy * 0.5;   // kéo dọc  → xoay X
    lastInteract = performance.now();
  });

  document.addEventListener('mouseup', () => {
    dragging = false;
    lastInteract = performance.now();
  });

  // --- Vòng lặp render ---
  function loop(now) {
    // tự xoay khi rảnh > 1.2s
    if (!dragging && now - lastInteract > 1200) {
      try_ += 0.3;
    }

    // lerp: góc hiện tại tiến dần tới góc mục tiêu
    rx += (trx  - rx)  * 0.12;
    ry += (try_ - ry)  * 0.12;

    cube.style.setProperty('--rx', rx + 'deg');
    cube.style.setProperty('--ry', ry + 'deg');

    requestAnimationFrame(loop);
  }
  requestAnimationFrame(loop);
</script>
</body>
</html>
```

---

Tóm 1 câu

Dựng 6 mặt bằng translateZ(½ cạnh) + rotateX/Y, đặt trong khối có perspective + preserve-3d, rồi cập nhật rotateX/Y mỗi frame bằng JS (kéo-thả + lerp + tự xoay) — tất cả bằng HTML/CSS/JS thuần.
