🎯 Flex vs Grid — So sánh trực quan

Cùng item — khác cách xếp. Nhìn là thấy ngay.

📐 FLEX

display: flex

Flex = xếp phần tử theo 1 hàng hoặc 1 cột. Phù hợp cho thanh điều hướng, danh sách, căn giữa.

gap: 12px;

📐 GRID

display: grid

Grid = xếp phần tử thành lưới 2 chiều (hàng + cột). Phù hợp cho layout trang, dashboard, gallery.

❌ Overkill cho: 1 hàng đơn giản.

📋 Bảng tóm tắt

Tiêu chí Flex Grid
Chiều 1 chiều (hàng HOẶC cột) 2 chiều (hàng VÀ cột)
Khai báo display: flex; display: grid;
Khoảng cách gap: 12px; gap: 12px;
Dùng khi Nav, list, căn giữa, toolbar Layout trang, dashboard, gallery
Responsive flex-wrap: wrap; auto-fit / auto-fill
Độ phức tạp Đơn giản hơn Mạnh hơn, phức tạp hơn
💡 Quy tắc chọn nhanh:
• Xếp 1 hàng hoặc 1 cột → dùng FLEX.
• Xếp lưới nhiều hàng + cột → dùng GRID.
• Không chắc → dùng FLEX cho đơn giản, GRID khi cần kiểm soát layout phức tạp.
