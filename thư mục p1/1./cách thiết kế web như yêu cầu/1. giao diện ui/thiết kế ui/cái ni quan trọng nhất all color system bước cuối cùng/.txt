5. COLOR SYSTEM ENGINE

Mỗi phong cách phải có một Color System riêng.

Tự động thiết lập các CSS Variables phù hợp.

Ví dụ hệ thống biến:

:root { /* Primary */ --primary: ; --primary-hover: ; --primary-active: ; /* Background */ --bg: ; --surface: ; --surface-secondary: ; /* Text */ --text-primary: ; --text-secondary: ; --text-muted: ; /* Border */ --border: ; --border-hover: ; /* Status */ --success: ; --error: ; --warning: ; --info: ; /* Effects */ --shadow: ; --focus-ring: ; /* Radius */ --radius-sm: ; --radius-md: ; --radius-lg: ; } 

Đây là hệ thống tham khảo, được phép điều chỉnh hoặc bổ sung biến khi cần thiết.

Yêu cầu:

Tên biến dễ hiểu.

Không khai báo biến trùng lặp.

Không tạo biến không có mục đích.

Không để biến được khai báo nhưng không sử dụng.

Các thành phần phải sử dụng đúng biến tương ứng.

Không sử dụng màu HEX trực tiếp tràn lan khi đã có biến phù hợp.

6. PRIMARY COLOR RESTRICTIONS

Không tự động thêm gradient cho H1.

7. SUCCESS & ERROR SYSTEM

Hai biến này phải được sử dụng đúng chức năng.

Success

--success

Sử dụng cho:

Thông báo thành công.

Trạng thái hoàn tất.

Kết quả submit thành công.

Error

--error

Sử dụng cho:

Thông báo lỗi.

Trạng thái thất bại.

Kết quả submit không thành công.

Đặc biệt: #msg

Nếu source code có phần tử #msg dùng để hiển thị kết quả submit:

Submit thành công: sử dụng --success.

Submit thất bại: sử dụng --error.

Phải kiểm tra cả CSS và JavaScript để bảo đảm màu sắc thực sự được áp dụng.

Không chỉ khai báo biến mà không sử dụng.

Không làm mất chức năng submit ban đầu.
