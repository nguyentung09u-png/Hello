1. gap
gap giúp tăng khoảng cách cho các ô item



ví dụ chưa :
.container {
  display: flex;
  /* flex-wrap: nowrap; ← mặc định */
}
┌─────────────────────────────────────────┐
│  Khung chứa (rộng 500px)                │
│                                         │
│  ┌────┐ ┌────┐ ┌────┐ ┌────┐ ┌────┐    │
│  │ 1  │ │ 2  │ │ 3  │ │ 4  │ │ 5  │    │
│  └────┘ └────┘ └────┘ └────┘ └────┘    │
│                                         │
└─────────────────────────────────────────┘
              ↑
   5 item xếp 1 hàng, TRÀN RA NGOÀI khung
   (hoặc bị bóp nhỏ lại để vừa)
   
   
   
   
-----

   ví dụ đã có gap :
   
   .container {
  display: flex;
  flex-wrap: wrap;   /* ← bật gấp */
  gap: 12px;
}┌─────────────────────────────────────────┐
│  Khung chứa (rộng 500px)                │
│                                         │
│  ┌────┐ ┌────┐ ┌────┐                   │
│  │ 1  │ │ 2  │ │ 3  │  ← Hàng 1         │
│  └────┘ └────┘ └────┘                   │
│                                         │
│  ┌────┐ ┌────┐                          │
│  │ 4  │ │ 5  │  ← Hàng 2 (tự xuống)     │
│  └────┘ └────┘                          │
│                                         │
└─────────────────────────────────────────┘
              ↑
   Item 4, 5 tự XUỐNG DÒNG khi hàng 1 hết chỗ
