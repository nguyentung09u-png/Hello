1. flex wrap giúp nếu item hết chỗ thì nó sẽ tự xuống dòng và sắp xếp

ví dụ : đây là khi hết chỗ
┌─────────────────────────────┐
│ ┌──┐┌──┐┌──┐┌──┐            │
│ │1 ││2 ││3 ││4 │            │
│ └──┘└──┘└──┘└──┘            │
└─────────────────────────────┘


sau khi sài flex wrap nó sẽ tự canh chỉnh và xuống dòng  :


.container {
  display: flex;
  flex-wrap: wrap;   /* ← cho phép xuống dòng */
  gap: 40px;
}

┌─────────────────────────────┐
│ ┌──┐┌──┐┌──┐┌──┐            │
│ │1 ││2 ││3 ││4 │  ← giữ cũ  │
│ └──┘└──┘└──┘└──┘            │
│ ┌──┐                        │
│ │5 │  ← xuống dòng mới      │
│ └──┘                        │
└─────────────────────────────┘


┌─────────────────────────────┐
│ ┌──┐┌──┐┌──┐┌──┐            │

└─────────────────────────────┘
